接收（收集）

文件保管

通过接收功能，可在文件一览内对上传完毕的文件进行保存。
文件被保存之前，可无限次上传此文件。保存后，原来发送文件的收集申请邮件的发件人，则不能再上传此文件。

保存文件夹指定功能的设定为有效的情况

只有“保存方文件夹指定功能”的设定有效时，才可以在收集邮件中指定文件夹进行保存。
请点击指定文件夹名。

点击指定文件夹名，把文件移动到文件一览的指定文件夹。

保存文件夹指定功能的设定为无效时

「保存文件夹指定功能」的设定为无效时，保存在文件一览的顶部。
请点击「保存」按键。

点击“保存”按键，移动至收集文件保存（确认）页面。请对需要保存的文件进行确认。点击“保存”按键后，文件将保存在文件一览内。

收集文件已保存。
