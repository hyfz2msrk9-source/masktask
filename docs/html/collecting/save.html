引取り(収集)

ファイルの保管

引取り機能によって、アップロードしてもらったファイルを、ファイル一覧に保管します。
保管するまでは、何度でもファイルをアップロードできます。保管すると、ファイルの収集依頼メールを送信した人からのファイルのアップロードができなくなります。

保管先フォルダ指定機能の設定が有効の場合

「保管先フォルダ指定機能」の設定が有効になっている場合のみ、収集メールで指定したフォルダに保管することができます。
指定フォルダ名をクリックしてください。

指定フォルダ名をクリックすると、ファイル一覧の指定されたフォルダにファイルが移動します。

保管先フォルダ指定機能の設定が無効の場合

「保管先フォルダ指定機能」の設定が無効の場合は、ファイル一覧のトップに保管されます。
[保管]ボタンをクリックしてください。

[保管]ボタンをクリックすると、収集ファイル保管(確認)画面に遷移します。 保管するファイルを確認してください。 [保管する]ボタンをクリックすると、ファイル一覧に保管します。

収集ファイルを保管しました。
