接收（收集）

文件保管

通過接收功能，可在文件一覽內對上傳完畢的文件進行保存。
保存期間內，可無限次上傳此文件。保存後，原來發送文件的收集申請郵件的寄件者，則不能再上傳此文件。

保存資料夾指定功能的設定為有效的情況

只要「保存方資料夾指定功能」的設定有效，收集郵件可對指定資料夾進行保存。
請點擊指定資料夾名。

點擊指定資料夾名，把文件移動到文件一覽的指定資料夾。

保存資料夾指定功能的設定為無效時

「保存資料夾指定功能」的設定為無效時，保存在文件一覽的頂部。
請點擊「保存」按鍵。

點擊「保存」按鍵，移動至收集文件保存（確認）頁面。請對需要保存的文件進行確認。點擊「保存」按鍵後，文件將保存在文件一覽內。

收集文件已保存。
