接收（收集）

接收（收集）是：為了確保文件的接收空間，把文件收集通知郵件發給特定收件人，在網路系統上上傳文件的功能。
目錄：請點擊接收（收集）

收集檔案一覽

菜單：點擊收集（接收），進入到「收集文件一覽」頁面。
利用接收功能，顯示上傳完畢的文件一覽。在「收集文件一覽」頁面裡，可以對各資料夾進行操作。

[發送接收郵件] 請點擊「發送接收郵件」按鍵。(→文件收信)
[發送從自己的郵箱
接收郵件]		 請點擊「發送從自己的郵箱接收郵件」按鍵。(→文件收信（从邮箱发送）)
標籤一覽 是為了[收集郵件]及管理領去的文件的標籤的一覽。
單擊各標籤的話，標籤被分配的文件一覽被表示。
[更改表簽名] 在標籤一覽中，可以對現在選定的標籤名進行更改。
[刪除標籤] 進行標籤刪除。標籤刪除後，此標籤管理下的收集文件及收集郵件也將一併刪除。
收集文件刪除後，接收URL將失效，請注意！
文件一覽 顯示已接收文件的資訊。
文件名 是文件名。「未登錄」表示文件未上傳的狀態。
是文件的詳情鍵。點擊這個按鍵，顯示接收時輸入的發信人的詳細資訊及登錄日期。
點擊「隱藏詳細」按鍵，則詳情關閉。()
登錄日 是文件上傳時的年月日或者時分秒。上傳當天可顯示至時分秒，如隔天則只顯示年月日。
大小 是文件的大小。

「更改標籤」時，點擊更改的標籤，則更改完成。
