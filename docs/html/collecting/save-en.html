Store files

You can store the file that is uploaded to be collected in the file list.
Until store the file, the file is able to be uploaded again. After you store the file in the file list, it is not be able to upload files with the URL in the mail to collect files.

In case “Save folder function“ is available

In case “Save folder function“ is available, the file can store files in the folder specified with the collection mail.
please click the specified folder name.

When you click the specified folder name the file moves to the specified folder.

In case “Save folder function“ is invalid

In case “Save folder function“ is invalid, the file of the file list is kept in the top.
Please click [Store] button.

When you click [Store] button the screen of collection file stored (confirm) is appeard.
Please confirm the file you want to store.
When you click the [Store] button, the file will be stored in the file list.

The collected file was stored.
