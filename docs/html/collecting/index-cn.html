接收（收集）

接收（收集）是：是为了确保文件的接收空间，把文件收集通知邮件发给特定收件人，让收件人把文件上传到网络系统上的功能。 目录：请点击接收（收集）

收集文件一览

菜单：点击收集（接收），进入到“收集文件一览”页面。
利用接收功能，显示上传完毕的文件一览。在“收集文件一览”页面里，可以对各文件进行操作。

[发送接收邮件] 请点击“发送接收邮件”按键。(→文件收信)
[从本管理器发送邮件
文件的收集]		 请点击“从本管理器发送接收邮件”按键。(→从本管理器发送接收邮件)
标签一览 是为了收集邮件及管理收集的文件的标签的一览
单击各标签的话，将显示被分配到该标签的文件一览。
[更改表签名] 在标签一览中，可以对现在选定的标签名进行更改。
[删除标签] 进行标签删除。标签删除后，此标签管理下的收集文件及收集邮件也将一并删除。
收集文件删除后，接收URL将失效，请注意！
文件一览 显示已接收文件的信息。
文件名 是文件名。“未登录”表示文件未上传的状态。
是文件的详情键。点击这个按键，显示接收时输入的发信人的详细信息及登录日期。 点击(关闭详情)按键，则详情关闭。
登录日 是文件上传时的年月日或者时分秒。上传当天可显示至时分秒，如隔天则只显示年月日。
大小 是文件的大小。
是“下载”键。进行文件的下载。
如接收“指定文件夹”，则不能从接收一览表中下载。
是“保存”键。进行文件的保存。(→文件保管)
如接收“指定文件夹”，将显示指定文件夹的名称。
是“删除”键。进行文件的删除。
删除文件，将同时在系统里完全删除。请小心操作！
是“标签更改”键。可对接收的文件及邮件的标签进行更改。
对选定的文件进行操作
对复选框里已选定的文件进行操作。
点击“保存”键，保存文件。保存完毕的文件，菜单：移至文件一览。点击“删除”键，删除文件及接收空间。
“更改标签”时，点击更改的标签后可更改该标签。
