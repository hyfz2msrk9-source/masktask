設定

署名一覧

メールの署名です。[署名]ボタンをクリックしてください。

署名一覧画面を表示します。

署名作成・編集

署名を作成・編集します。
作成する場合は[作成する]ボタンを、編集する場合は編集したい署名をクリックしてください。

署名の作成・編集・削除画面に遷移します。
項目を入力し、[編集確定]ボタンをクリックしてください。

名前 署名の名前です。ファイルの配布やファイルの収集時のメール本文には挿入されません。
署名 署名です。ファイルの配布やファイルの収集時のメール本文に挿入されます。

署名削除

署名を削除します。削除したい署名をクリックしてください。

署名の作成・編集・削除画面に遷移します。
内容を確認し、[削除する]ボタンをクリックしてください。

[削除する]ボタンをクリックすると、確認メッセージが表示されます。
[OK]ボタンをクリックすると、署名は削除されます。
