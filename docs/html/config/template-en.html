Settings

Template

You can create or edit email templates for mail.

Email template list will appear.

Template Creation and Editing

You can create or edit email templates.
To create a new template, click the [Add] button.
To edit an existing template, click the [Details] button for the template you want to edit.

＊For Editing
Click the [Edit] button at the bottom of the Email Template Details screen to enable editing.

You will be taken to the email template creation and editing screen. Please fill in the required fields and click the [Save] button.

Template name This is the name of the email template.
It will not be included in the email.
Type Select the feature where the template will be used.
Distribution Available for Distribution and Folder publication.
Collection Available for Collection and Gathering.
Email subject It will be inserted into the email subject line.
Email text It will be inserted into the body of the email.
[##mail##] Change into Email each address that Emails are sent to.
[##name##] Change into each name that Emails are sent to.
[##addr_list##] Change into the destination list.
[##dl_limit##] Change into the term of validity of downloading files.
[##url##] Change into file download URL for each addresses.
[##file_list##] Change into the sent file list.
[##upload##] Change into file upload URL for each addresses.
[##up_limit##] Change into the term of validity of uploading files.
Security settings
　Download		 These are the security settings for file downloads.
Download expiry date You can set the period during which the file is available for download.
Maximum number of downloads You can set the maximum number of times the file can be downloaded.
Do not set a password Anyone with the URL can download the file.
Set a one-time password When accessing the URL, a one-time password that can be used only once will be sent to the recipient.
Set a one-time password
(Send via a different route)		 The one-time password can be sent to an alternative email address or phone number via SMS, instead of the intended recipient.
Set a specified password You can set a password that will be required to download the file.
Access Notification You will receive a notification each time the download URL is accessed.
Download Notification You will receive a notification when the file is actually downloaded.
Automatic File Deletion The file will be automatically deleted after the download period expires.
Security settings
　Upload		 These are the security settings for file uploads.
Upload expiry date You can set the period during which the upload URL is valid.
Do not set a password Anyone can upload files without a password.
Set a one-time password A one-time password required for uploading will be generated.
Set a specified password You can set a password that will be required to upload files.
Upload Notification The uploader will receive a notification with file information each time a file is uploaded.
Character Encoding You can switch between ISO-2022-JP and UTF-8.

Template Duplicate And Delete

Click the [Details] button for the target email template.

＊For duplication
Review the content and click the [Duplicate] button.
After that, you can create a new template using the same steps as editing an email template.

＊For deletion
Review the content and click the [Delete] button.

When you click [Delete] button, message dialogue to confirm will appear. Please click [OK] button, the template you made is deleted.

Calling a Template

You can select the created template from the [Template] on the email creation screen.

The selected template will be applied to the email creation screen.
