設定

寄件者設定

分發或收集的郵件，可以同時發送給多名收件人。
發送完畢後，可根據需要，更改寄件者的名字或郵箱地址，另作他用。
請點擊“寄件者設定”按鍵。

移動至寄件者設定頁面。
在寄件者設定頁面裡顯示登錄的寄件者名一覽。

設定寄件者名

設定寄件者名。
點擊[追加寄件者]按鈕。

移動至寄件者追加頁面。
在「設置為默認」裡打鉤，所作成的寄件者名會被設置為默認。
輸入必填專案，點擊[進入確認頁面]按鈕。

移動至追加寄件者確認頁面。
確認內容無誤請點擊[追加]按鈕。

系統會發確認郵件到已登錄的郵箱地址。
點擊郵件中的URL連接完成登錄。

點擊郵件內的URL連接移動至設定寄件者確認頁面。

確認可以設定寄件者名請點擊[批准]按鈕。
移動至寄件者認證完成頁面。完成追加寄件者名。

取消設定寄件者名請點擊[駁回]按鈕。
移動至寄件者認證完成頁面，取消寄件者名的設定。

沒有收到認證郵件時，請點擊[郵件重發]按鈕再次發送郵件。

編輯寄件者名

編輯寄件者名。點擊想要編輯的寄件者名的[編輯]按鈕。

移動至寄件者編輯頁面。輸入必填專案點擊[確定編輯]按鈕。

刪除寄件者名

刪除寄件者名。點擊想要刪除的寄件者名的[刪除]按鈕。

系統會顯示確認資訊，沒有問題請點擊[OK]按鈕。
刪除寄件者名。
