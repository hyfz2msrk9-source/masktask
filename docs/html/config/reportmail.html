レポートメール設定

活動状況を定期的に送るレポートメールの設定をおこないます。
レポーメール設定の[設定]ボタンをクリックしてください。
レポートメール設定画面に遷移します。

レポートメールの設定をおこなう

レポートメール レポートメール利用の有無を変更します。
送信間隔 レポートメールを配信する間隔を変更します。
送信時間 レポートメールを配信する時間を変更します。
レポート内容 レポート内容では、レポートする内容の選択とその順番を変更します。
レポート内容に含める場合は項目横のチェックボックスを選択し
お好みの順番をご選択ください。
ファイル
・アップロードしたファイル
・定期削除したファイル
・10日以内に定期削除を予定するファイル
配布
配布メールを通知した日時やファイル情報
収集
収集メールを通知した日時やファイル情報
パスワード
パスワード変更履歴

変更した内容でよろしければ[完了]ボタンをクリックしてください。完了画面へ遷移します。
