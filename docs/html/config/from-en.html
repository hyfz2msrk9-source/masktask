Settings

Sender setting

You can register two or more sender name of the distribution and collecting files.
You are able to send email of file notification with another sender name and email address that you registered according to the usage.
Please click the [Sender setting] button.

List of sender setting will appear.
The list of the registered name of the sender is displayed on the sender setting screen.

Setting of the sender name

You can set the sender name.Please [ Create sender ] button.

You move to the screen to create sender.
If you check [Default setting] on, it name is set as a default sender name.
Please input a necessary item, and click on a button to the confirmation screen.

You move to the screen to confirm of the created sender.
Please click the made button if the content is correct.

The mail of the confirmation is send to the registered email address appropriating.
Please complete registration clicking URL described in mail.

When URL in email is clicked,it changes to the sender setting confirmation screen.

Please click [Approve] button if you may set the name of the sender.
The screen changes to List of sender setting(completion) screen, and the name of the sender is added.

Please click [Reject] button if you may not set the name of the sender.
The screen changes to List of sender setting(completion) screen, and the name of the sender is not added.

Please transmit mail again clicking the [Mail] button when mail is not confirmed.

Edit the name of the sender

Edit the sender name. Please click the [edit] button of the edited name of the sender.

It changes to the sender edit screen. Please input a necessary item, and click [Submit] button.

Delete the sender name

You can delete the sender name you registered. Please click the [Delete] button by the sender that you want to delete.

The confirming message is displayed.
After confirming, please click [OK] button.The name of the sender is deleted.
