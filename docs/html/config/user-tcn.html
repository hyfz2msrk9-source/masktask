組共用

用戶管理

操作關於組共用的設定。點擊[用戶管理]按鈕。

移動到用戶管理頁面。
在用戶管理頁面裡，顯示所管理的組裡的用戶一覽。

新增用戶

在用戶管理頁面裡可以新增用戶。點擊[追加]按鈕。

移動至用戶追加頁面。
組存取權限只有組管理員才顯示。輸入必填專案、點擊[追加]按鈕。

認證方法
※在請使用複數的認證方法的時候，能要設定。

如果您選擇Google SSO身份驗證，請在您的帳戶中輸入用戶的Google帳戶。

如果您選擇[##SAML_NAME##]，請在您的帳戶中輸入用戶的郵件地阯。

移動至用戶追加（確認）頁面。確認內容無誤請點擊[追加]按鈕。

移動至用戶追加（完成）頁面。完成用戶追加。

用戶編輯

進行用戶編輯。點擊想要編輯的用戶的[編輯]按鈕。

移動至用戶編輯頁面。密碼只有在需要更改的時候才輸入。

文件鎖功能為有效時，資料夾許可權頁面裡會顯示用語。
上鎖的用戶的資料夾許可權改為「唯讀」時，文件的鎖會得到解除。
關於帶鎖下載(→加密下載)

輸入必填專案，點擊[編輯]按鈕。

認證方法
※在請使用複數的認證方法的時候，能要設定。

如果您選擇Google SSO身份驗證，請在您的帳戶中輸入用戶的Google帳戶。

如果您選擇[##SAML_NAME##]，請在您的帳戶中輸入用戶的郵件地阯。

移動至用戶編輯（確認）頁面。確認內容無誤請點擊[確定編輯]按鈕。

移動至用戶編輯（完成）頁面。完成用戶編輯。

刪除用戶

進行用戶刪除。點擊想要刪除的用戶的[刪除]按鈕。

移動至用戶刪除（確認）頁面。
確認可以刪除用戶請點擊[刪除]按鈕。

移動至用戶刪除（完成）頁面。完成用戶刪除。

IP Restrictions

IP restrictions are the functions to which access restriction can be applied by an IP address for every group. They are firmer security countermeasures of the group treating confidential information.
In each group unit, IP address registration can be performed with a use setup.
When it is set as "Only a registration IP address can be accessed.", only a registration IP address permits access and can perform an inspection and operation of a file.

IP restrictions of each group

Please click [IP Restrictions] button.

share groups list of IP Restrictions screen will appear.
Click the [Setup] button of a group. It becomes a setting screen of IP restrictions of each group. [Setup] When undisplayed, there is no Permission.

Effective and invalidity of IP restrictions

A setup of "Access is more possible than all the IP." or "Only a registration IP address can be accessed." can be performed to each group.
Please click after selection the button under a screen [Update].

The registration of an IP address should click and perform the button of the bottom on the right-hand side of a screen [Edit].

Edit IP address

You can edit IP address here.Please click [Edit] button.IP address edit screen will appear.
In an IP address edit display, addition of the IP address which can be accessed, and deletion can be performed.
Please input the IP address registered into the IP address column, and click a [Add] button. An IP address is added to an IP address list. A subnet mask is also OK.

When you delete a registered IP address, please choose the IP address under list and push [Delete] button. An IP address is deleted.
Edit of an IP address cannot be performed. Please delete and add the IP address of relevance.
