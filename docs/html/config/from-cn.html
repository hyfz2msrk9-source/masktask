发件人设定

分发或收集文件的邮件的发件人，可以复数登录。
登录的发件人，可根据需要使用不同的发件人名或邮箱地址。
请点击“设定发件人”按键。

移动至发件人设定页面。
在发件人设定页面里显示登录的发件人名一览。

设定发件人名

设定发件人名。
点击[追加发件人]按钮。

移动至发件人追加页面。
在「设定为默认」里打钩，所作成的发件人名会被设置为默认。
输入必填项目，点击[进入确认页面]按钮。

移动至追加发件人确认页面。
确认内容无误请点击[追加]按钮。

系统会发邮件确认到已登录的邮箱地址。
点击邮件中的URL链接完成登录。

点击邮件内的URL链接移动至设定发件人确认页面。

确认可以设定发件人名请点击[确认]按钮。
移动至发件人认证完成页面。完成追加发件人名。

取消设定发件人名请点击[取消]按钮。
移动至发件人认证完成页面，取消发件人名的设定。

没有收到认证邮件时，请点击[邮件重发]按钮再次发送邮件。

编辑发件人名。

编辑发件人名。点击想要编辑的发件人名的[编辑]按钮。

移动至发件人编辑页面。输入必填项目点击[确定编辑]按钮。

删除发件人名

删除发件人名。点击想要删除的发件人名的[删除]按钮。

系统会显示确认信息，没有问题请点击[OK]按钮。
删除发件人名。
