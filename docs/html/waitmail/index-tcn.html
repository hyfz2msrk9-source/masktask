待機郵件一覽

待機郵件一覽是指待機狀態還未被發出的郵件一覽。
分佈，傳輸並在同一時間採取回電子郵件通訊，發送郵件自動隨著時間的推移，等待時間設置為發送電子發送郵件收回。
目錄：請點擊待機郵件一覽。

以下介面是待機郵件的一覽。

動作 顯示送信郵件的種類。
收件人 顯示送信郵件的郵箱地址。
文件名 顯示送信郵件裡附件的名字。
件名 顯示發送郵件的件名。
發送預訂時間 顯示發送郵件的時間。
發送狀態 顯示郵件的狀態。
詳細 對發送待機中的郵件進行編輯和確認。

待機郵件的詳細

在一覽中選擇想要確認的郵件點擊[詳細]按鈕。

顯示郵件的詳細頁面。
在詳細頁面裡可以進行郵件的編輯、刪除、發送停止解除。

待機郵件的編輯

在詳細頁面裡店家[編輯]按鈕，顯示編輯頁面。

更改內容後點擊[移至確認頁面]按鍵。移動到確認頁面。
確認完了後移動至待機郵件一覽頁面。
如果你已經設置了傳輸延遲，並更新在設定的時間，它會被發送到更改時間。

解除"發送停止"

在編輯待機郵件時移動到其他頁面，被編輯中的待機郵件會改為發送停止狀態。使用解除“發送停止”功能能夠解除發送停止狀態的待機郵件。
點擊詳細頁面中的[解除“發送停止”]按鈕，移動至解除發送停止頁面。

移動至解除發送停止頁面。
可以解除的話請點擊[確定]按鈕。完成解除發送停止。

刪除待機郵件

點擊詳細頁面裡的[刪除]按鈕，會顯示確認框。
確認要刪除請點擊[OK]按鈕。完成待機郵件的刪除。
