遇到需要輸入臨時密碼時

領取臨時密碼（使用一次後，不能再用第二期的密碼形式），下載加密資料。密碼會在每次下載時以郵件的形式獲得。

電子郵件地址輸入頁面

需要領取密碼時，請輸入收到通知郵件的人的郵箱地址。
如果輸入其他人的郵箱地址，或把郵件轉發後輸入轉發收件人的郵箱地址是無法收到密碼的。如果遇到這種情況請輸入最初收到通知郵件的人的轉發前的郵箱地址。

比如，「○○＠sample.co.jp」的郵箱地址收到郵件，自動轉發給「▲▲@mailaddress.com」後確認過郵件的，請輸入「○○＠sample.co.jp」的郵箱地址。

輸入郵箱地址後點擊[發送]按鈕。

輸入正確的郵箱地址時
系統會把密碼以郵件的形式發送到輸入的郵箱地址裡，打開密碼輸入頁面。
輸入錯誤的郵箱地址時
系統會提示錯誤資訊，無法進入密碼輸入頁面。

輸入密碼頁面

輸入正確的郵箱地址後，輸入的郵箱地址會收到件名為「下載用密碼的通知」的郵件。

把郵件內的密碼輸入到密碼發送頁面內的密碼欄裡，點擊「發送」按鈕。

輸入正確的密碼後
會打開文件下載頁面。
輸入錯誤的密碼後
系統會提示錯誤，無法進入下載頁面。點擊「重新領取密碼」按鈕回到郵箱地址輸入頁面。
重新開始獲取一次性密碼
如果你想從獲得一次性密碼開始，請點擊屏幕上方的步驟列表中的「輸入電子郵件地址」。 您可以通過輸入您的電子郵件地址重新開始。

下載頁面

點擊文件名或屏幕右側的下載按鈕即可下載文件。
