Download with the one-time password

One-time password is a kind of password that can be used 1 time and after that the same password is not available. You can get the one-time password and download the files with the password. You have to get the password every time you want to download. You can get the password with Email.

Input form for email address

Please enter the email address you received the download URL from, and then click [Enter] button.

If you enter the Email address that is different address of the original receiver or the address that is forwarded for not the original, it is impossible to get the one-time password. If you receive the forwarded Email, please enter the address of the original receiver.

If the Email was received “○○@sample.co.jp” first, and Ms. / Mr. Green forwards this Email to you as “▲▲@mailaddress.com.” In this case, you enter “○○@sample.co.jp “ to get one-time password.

In case that the Email address is correct
The one-time password is sent to the address that you entered, and the screen to enter the password is open.
In case that the Email address is incorrect
The error message is displayed and the screen to enter the password is not open.

Input form for password

When the address that you enter is correct, the password is sent by Email “Notification of password for downloading”.

Please enter the password which is given in the password, and click the [Enter] button.

In case that the password is correct
The download files screen is opened.
In case that the password is not correct
The error message is displayed and the screen to download files is not open.
Click [Redo from beginning] button, you can redo from getting one-time password.
Restarting from getting a one-time password
If you want to start over with getting a one-time password, please click the [Mail address] buttonin the step list at the top of the screen. You can start over by entering your email address.

Download page

When the download screen opens, click on the name of the file you want to download or the download button on the right side of the table. The download will begin.
