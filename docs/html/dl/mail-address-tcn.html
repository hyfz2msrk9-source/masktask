遇到需要輸入郵箱地址時

點擊訪問郵件內的下載URL連結時，遇到要求輸入郵箱地址的情況。
是為了確認是否是指定的用戶在進行下載。請輸入收到郵件的人的郵箱地址。

如果輸入其他人的郵箱地址，或把郵件轉發後輸入轉發收件人的郵箱地址是無法下載資料的。如果遇到這種情況請輸入最初收到通知郵件的人的轉發前的郵箱地址。

比如，用「○○＠sample.co.jp」的郵箱地址收到郵件，自動轉發給「▲▲@mailaddress.com」後確認過郵件的，請輸入「○○＠sample.co.jp」的郵箱地址。

輸入正確的郵箱地址

輸入正確的郵箱地址後，移動到下載頁面。
點擊想要下載的文件右側的[下載]按鈕，或直接點擊文件名進行下載。

輸入錯誤的郵箱地址時

系統顯示錯誤提示，無法進入下載頁面。
