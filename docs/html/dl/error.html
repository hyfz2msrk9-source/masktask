配布メールを受け取った方（ダウンロード）

ファイルのダウンロード

ダウンロードできない場合

以下のような画面やメッセージが表示される場合は、ファイルのダウンロードが出来ません。メールの送信者までお問合せください。

ダウンロードが規定回数を超えています
送信者が指定したダウンロード回数に達したため、ダウンロードができません。
ダウンロード有効期限を過ぎています
送信者が指定したダウンロード期限を過ぎたため、ダウンロードができません。
ダウンロードが中止されています
送信者によってファイルの削除が行われたか配布が中止されたため、ダウンロードできません。
URLが正しくありません
通知されたダウンロードURLに誤りがあり、ダウンロード画面に正しくアクセスできません。
