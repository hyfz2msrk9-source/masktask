Download files

About download files

It is a very simple operation that the receivers of the distribution Email access the URL in the Email and click the [Download] button to download files.

The ordinary download
When you receive the Email that inform you the distribution of the data, please click the URL to download files.
When the download page opens, click on the name of the file you want to download or the download button on the right side of the table. The download will begin.

Zip file download
When you receive the Email that inform you the distribution of the data, please click the URL to download files.

When the download screen opens, click on the name of the file you want to download or the download button on the right side of the table. The download will begin.
The file is compressed into the zip file. And, the password is set.
Please ask the sender when you do not know the password.

Folder publication
Please click URL for download in email after receiving the notification of folder publication.

When the folder publication page opens, please click on the name of the file you want to download or the download button on the right side of the table. The download will begin.
Please click on [Download all files] button if you want to download the files to which you are displayed by the batch. After that it changes to the confirmation screen.

Please click on a button when you execute download after you confirm. The file will be compressed.

After the compression of the file ended, please click the [Download the zip folder] button and download the file.
