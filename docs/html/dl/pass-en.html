Download with specified password

You can reach the download screen using specified password that is given by the sender of the file.
If you are required to enter the password not to enter the Email address, you have to enter the password that is set by the sender of files. If you do not know the password, please ask sender of the Email.

Please enter the password that sender of this Email inform you, and click the [Send password] button.


Example: You get password by the Email from sender.

In case you enter the correct password.
The download files screen is opened.
Click on the name of the file you want to download or the download button on the right side of the table. The download will begin.
In case you enter the incorrect password.
The error message is displayed and the screen to download files is not open.
