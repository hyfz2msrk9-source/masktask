文件下載

關於文件下載

點擊訪問郵件內的URL連結，在下載頁面中選擇需要的文件點擊[下載]按鈕的簡單操作。

標準下載
收到資料發送的通知郵件後，點擊郵件中的下載用URL連結。

當打開數據下載界面時，您可以選擇要下載的文件的文件名，或選擇點擊屏幕右側的下載按鈕。
下載將開始。

ZIP文件下載
收到資料發送的通知郵件後，點擊郵件中的下載用URL連結。
當打開數據下載界面時，您可以選擇要下載的文件的文件名，或選擇點擊屏幕右側的下載按鈕。 下載將開始。
被壓縮為ZIP文件的文件有設置密碼。
如果不知道密碼，請聯繫寄件者。

資料夾公開
收到資料夾公開的通知郵件後，點擊郵件中的下載用URL連結。
打開了資料夾公開頁面，點擊想要下載的文件右側的[下載]按鈕，或者點擊文件名開始下載。


要下載所有顯示的文件請點擊[下載全部文件]按鈕。移動至下載壓縮文件夾頁面。

確認可以打包下載請點擊[下載壓縮文件夾]按鈕。開始壓縮文件。

文件壓縮完畢後點擊[下載壓縮文件夾]按鈕進行下載。
