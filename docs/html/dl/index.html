配布メールを受け取った方（ダウンロード）

ファイルのダウンロード

ファイルダウンロードについて

メール内に記載されたURLへアクセスし、ダウンロード画面から[ダウンロード]ボタンで必要なファイルをダウンロードするだけの簡単操作です。

通常ダウンロード
データの配布をお知らせするメールを受信されましたら、メール内に記載されている、ダウンロード用URLをクリックしてください。
ダウンロード画面が開きましたら、ダウンロードしたいファイルのファイル名か、表の右端に表示されたダウンロードボタンをクリックしてください。ダウンロードが開始されます。

ZIPファイルダウンロード
データの配布をお知らせするメールを受信されましたら、メール内に記載されている、ダウンロード用URLをクリックしてください。

ダウンロード画面が開きましたら、ダウンロードしたいファイルのファイル名か、表の右端に表示されたダウンロードボタンをクリックしてください。ダウンロードが開始されます。
ZIPファイルに圧縮されたファイルは、パスワードが設定されています。
パスワードが分からない場合は送信者にお問い合わせください。

フォルダ公開
フォルダ公開のお知らせするメールが受信されましたら、メール内に記載されている、ダウンロード用URLをクリックしてください。

フォルダ公開画面が開きましたら、ダウンロードしたいファイルのファイル名、または右横に表示されているダウンロードボタンをクリックしてください。ダウンロードが開始されます。


表示されているファイルを一括でダウンロードする場合は、[一括ダウンロード]ボタンをクリックしてください。フォルダ一括ダウンロード確認画面に遷移します。
一括ダウンロードしてもよろしければ、確認画面内の[一括ダウンロード]ボタンをクリックしてください。ファイルの圧縮が開始します。

ファイルの圧縮完了後、[一括ダウンロード]ボタンをクリックし、圧縮されたファイルをダウンロードしてください。
