关于文件下载

遇到需要输入一次性密码时

领取一次性密码（使用一次后，不能再用第二次的密码形式）后，下载加密数据。密码可在每次下载时以邮件的形式获得。

电子邮件地址输入页面

需要领取密码时，请输入收到通知邮件的人的邮箱地址。
如果输入其他人的邮箱地址，或把邮件转发后输入转发收件人的邮箱地址是无法收到密码的。如果遇到这种情况请输入最初收到通知邮件的人的转发前的邮箱地址。

比如，「○○＠sample.co.jp」的邮箱地址收到邮件，自动转发给「▲▲@mailaddress.com」后确认过邮件的，请输入「○○＠sample.co.jp」的邮箱地址。

输入邮箱地址后点击[送信]按钮。

输入正确的邮箱地址时
系统会把密码以邮件的形式发送到输入的邮箱地址里，打开密码输入页面。
输入错误的邮箱地址时
系统会提示错误信息，无法进入密码输入页面。

输入密码页面

输入正确的邮箱地址后，输入的邮箱地址会收到件名为「下载用密码的通知」的邮件。

把邮件内的密码输入到密码发送页面内的密码栏里，点击「发送」按钮。

输入正确的密码后
会打开文件下载页面。
输入错误的密码后
系统会提示错误，无法进入下载页面。点击「重试」按钮回到邮箱地址输入页面。
重新开始获取一次性密码
如果你想从获得一次性密码开始，请点击屏幕上方的步骤列表中的「输入电子邮件地址」。 您可以通过输入您的电子邮件地址重新开始。

下载页面

点击文件名或屏幕右侧的下载按钮即可下载文件。
