ファイルのダウンロード

メールアドレスの入力を求められる場合

メールに記載されているダウンロードURLへアクセスした際、メールアドレスの入力を求められる場合があります。
正しい相手がダウンロードを行ったかどうかを確認するものですので、メールを受け取られたご本人のメールアドレスを入力してください。

別の方のメールアドレスや、メールを転送している場合に、転送先のメールアドレスを入力しても、データはダウンロードできません。そのような場合は、最初にメールを受け取られた方の、転送前のメールアドレスを入力して下さい。
例えば、「○○＠sample.co.jp」のメールアドレスでメールを受信し、「▲▲@mailaddress.com」に自動転送して、メールを確認した場合、「○○＠sample.co.jp」の方を、入力してください。

正しいメールアドレスを入力した場合

正しいメールアドレスを入力後、ダウンロード画面に遷移します。
ダウンロードしたいファイルの右横に表示されている[ダウンロード]ボタン、または、ファイル名をクリックしてください。ダウンロードが開始されます。

誤ったメールアドレスを入力した場合

エラーメッセージが表示され、ダウンロード画面に進めません。
