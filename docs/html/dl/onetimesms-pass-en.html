Download files

Download with the one-time password(another destination)

One-time password is a kind of password that can be used 1 time and after that the same password is not available. You can get the one-time password and download the files with the password. You have to get the password every time you want to download. You can get the password with SMS(or Email).

Confirmation of destination

Please Check the phone number (or email address) to which you want to send the one-time password, and click the [Enter] button.
At this time, if it is not your own address, click the "Wrong phone number (or e-mail address)" button. Notify the sender of any mistakes.

Input form for password

When you press the enter button, an SMS (or email in the case of an email address) containing the password will be sent to the one-time password destination.

Please enter the password which is given in the password, and click the [Enter] button.

In case that the password is correct
The download files screen is opened.
In case that the password is not correct
The error message is displayed and the screen to download files is not open.
Click [Redo from beginning] button, you can redo from getting one-time password.
Restarting from getting a one-time password
If you want to start over from obtaining a one-time password, click [Phone number confirmatio(or Confirm E-mail Address)] in the procedure list displayed at the top of the screen. You can start over from the confirmation screen.

Download page

When the download screen opens, click on the name of the file you want to download or the download button on the right side of the table. The download will begin.
