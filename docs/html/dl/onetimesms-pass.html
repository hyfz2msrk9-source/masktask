配布メールを受け取った方（ダウンロード）

ファイルのダウンロード

ワンタイムパスワード（別経路）を求められる場合

ワンタイムパスワード（一度利用すると、二度目からは同じパスワードが利用できなくなる形式）を取得し、パスワード付きデータをダウンロードします。パスワードは、ダウンロードの度にSMS（もしくはメール）で取得します。

送信先の確認

ワンタイムパスワード送信先となる携帯電話番号（もしくはメールアドレス）を確認し、[送信]ボタンをクリックしてください。
この際、ご自身の宛先ではない場合、「電話番号（もしくはメールアドレス）が間違っている」ボタンを押してください。誤っていることを送信者に連絡し、対応させて頂きます。

パスワード入力画面

送信ボタンを押すと、ワンタイムパスワード送信先に、パスワードが記載されたSMS（メールアドレスの場合はメール）が届きます。

SMS（メールアドレスの場合はメール）内に記載されているパスワードをパスワード送信画面に入力し、 [送信]ボタンをクリックしてください。

正しいパスワードを入力した場合
ファイルのダウンロード画面が開きます。
誤ったパスワードを入力した場合
エラーメッセージが表示され、ダウンロード画面に進めません。「最初からやり直す」を押すと、メールアドレス入力段階に戻ります。
ワンタイムパスワードの取得からやり直したい場合
ワンタイムパスワードの取得からやり直したい場合は、画面上部に表示された手順リストの[電話番号確認（もくはメールアドレス確認）]をクリックしてください。確認画面からやり直せます。

ダウンロード画面

ダウンロード画面が開きましたら、ダウンロードしたいファイルのファイル名か、表の右端に表示されたダウンロードボタンをクリックしてください。ダウンロードが開始されます。
