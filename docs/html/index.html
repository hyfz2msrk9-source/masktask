本マニュアルについて

本マニュアルは、ユーザ側操作マニュアルです。

本マニュアル中の"[]"で囲まれた文字はボタンに表示されている文字テキストを示しています。
本マニュアル中の画面のイメージ(画像)は、お使いのブラウザによって、フォントや色彩等が違う場合があります。

ユーザについて

ファイルの配布、ファイルの引取り、アドレス帳、履歴、設定、 プロフィールからのパスワード変更などを行うことができます。設定により、ユーザ毎に様々な使い方に対応することができます。

初期設定について

システムを初めて利用される場合は、ユーザのパスワードを初期パスワードから変更してください。

ログイン

ログインしてください。(→ログイン)

パスワードを変更する

ログイン後、メニュー：プロフィールをクリックし、プロフィール欄の[パスワード変更]ボタンをクリックして、パスワードを変更してください。(→パスワード変更)
