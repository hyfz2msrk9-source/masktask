個人資訊

目前所登錄的個人資訊。可以更改密碼。
建議定期更換密碼。

目錄：點擊個人資訊。

更改密碼

更改密碼。請點擊[更改密碼]按鈕。
※使用Google SSO身份驗證或者[##SAML_NAME##]的用戶不能更改密碼。

移動至更改密碼頁面。輸入現在的密碼、新密碼、新密碼（確認）後點擊[確定編輯]按鈕。

更改密碼後系統自動退出。
請輸入新的密碼重新登錄。

雙因素認證

 ※使用Google SSO身份驗證或者[##SAML_NAME##]的用戶無法在WebFile中設置雙因素認證。
 ※此設置只適用於使用認證應用程序的雙因素認證。

啟用雙因素認證

在禁用雙因素認證時，請點擊在個人資訊中的[啟用]按鈕。

按照說明設置雙因素認證。請輸入確認碼並點擊[檢查並保存]。

禁用雙因素認證

在啟用雙因素認證時，請點擊個人資訊部分的[禁用]按鈕。

從閱讀說明，請點擊[關閉]。
