个人信息

目前所登录的个人信息。可以更改密码。
建议定期更换密码。

目录：点击个人信息。

更改密码

更改密码。请点击[更改密码]按钮。
※使用Google SSO身份验证或者[##SAML_NAME##]的用户不能更改密码。

移动至更改密码页面。输入现在的密码、新密码、新密码（确认）后点击[确定编辑]按钮。

更改密码后系统自动退出。
请输入新的密码重新登录。

双因素认证

 ※使用Google SSO身份验证或者[##SAML_NAME##]的用户无法在WebFile中设置双因素认证。
 ※此设置只适用于使用认证应用程序的双因素认证。

启用双因素认证

在禁用双因素认证时，请点击个人信息部分的[启用]按钮。

按照说明设置双因素认证。请输入确认码并点击[检查并保存]。

禁用双因素认证

在启用双因素认证时，请点击个人信息部分的[禁用]按钮。

阅读说明，然后请点击[禁用]。
