プロフィール

現在登録されているプロフィールです。パスワードの変更を行うことができます。
パスワードは定期的に変更されることを、お勧めいたします。

メニュー：プロフィールをクリックしてください。

パスワード変更

パスワードを変更します。[パスワード変更]ボタンをクリックしてください。
※Google SSO認証または[##SAML_NAME##]利用ユーザはパスワードを変更することはできません。

パスワード変更画面へ遷移します。現在のパスワード、新パスワード、新パスワード(確認)を入力し、[編集確定]ボタンをクリックしてください。

パスワードを変更すると、自動的にログアウトします。
変更後のパスワードで、再度ログインしてください。

二要素認証

 ※Google SSO認証または[##SAML_NAME##]利用ユーザはWebFileから二要素認証の設定を行うことはできません。
 ※認証アプリを使用して二要素認証を行う時のみ、二要素認証の設定を行うことが出来ます。

二要素認証を有効にする

無効になっている状態で、プロフィールに表示される[有効にする]ボタンをクリックします。

説明に沿って二要素認証の準備を行います。確認コードを入力して、[確認して保存]をクリックしてください。

二要素認証を無効にする

有効になっている状態で、プロフィールに表示される[無効にする]ボタンをクリックします。

説明を読んでから、[無効にする]をクリックしてください。
