上長承認一覧(※オプション)

上長承認機能は、オプション機能です。
上長承認機能とは、登録ファイルの配布(メーラー含む)、配布と収集(メーラー含む)、フォルダ公開(メーラー含む)、一斉配信を行った場合に、上長を選択し上長の承認を得た通知メールのみ配信される機能です。メーラーからの通知では、承認された際にダウンロードURLが有効になります。

メニュー：上長承認一覧をクリックしてください。

申請者向け機能（ユーザ側）

申請一覧

申請一覧では、申請の状態（承認待・進行中・完了・却下・キャンセル）に応じた一覧のほか、すべての状態をまとめて確認することが可能です。
「承認待」と「進行中」を合計した件数が、「申請一覧」の横に表示されます。
以下は「承認待」一覧の画面例です。

承認／却下／キャンセル通知

承認依頼中の通知メールは、上長から承認された後に宛先へ送信されます。
上長から承認がおりて通知メールが送信されると、送信者へメールでお知らせします。

上長から承認された場合のメール

上長から通知メールを却下された場合は、通知メールは配信されません。
また、却下された場合には、送信者へメールでお知らせします。メールには却下された理由が記載されますのでご確認ください。

上長から却下された場合のメール

上長が承認または却下を行うまでは、承認依頼をキャンセルすることが可能です。この場合、通知メールは配信されません。
また、キャンセルした場合には、上長へメールでお知らせします。メールにはキャンセルされた理由が記載されます。

キャンセルした場合に上長へ送信されるメール

「承認待」の件数が、「承認一覧」の横に表示されます。

上長承認での配布ファイルチェックが有効な場合
上長承認の際、上長は全ての配布ファイルを確認しなければ、承認を行えません。
※この機能はフォルダ公開・一斉配信には適用されません。

「ダウンロードされていません」と表示されている場合
承認を行うには全ての配布ファイルをダウンロードする必要があります。

「ダウンロードまたはプレビューされていません」と表示されている場合
承認を行うには全ての配布ファイルをダウンロードまたはプレビューする必要があります。
