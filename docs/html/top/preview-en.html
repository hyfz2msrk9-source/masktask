About the Preview Function

You can open the preview screen by double-clicking a file name in the file list or by clicking (available only for files that can be previewed).
CSV and Excel files exceeding 50,000 cells per sheet cannot be previewed.
Files larger than 200 MB cannot be previewed.
In Excel files, the layout may not be displayed correctly.
Files for which you do not have download permission cannot be previewed.
Files that can be previewed are as follows:

File Type Extension
PDF .pdf
Text .txt
CSV / Excel .csv, .xlsx, .xls
Image .jpeg, .jpg, .png, .bmp, .gif
Audio Files .mp3, .ogg, .opus, .wav, .m4a
Video Files .mov, .mp4
