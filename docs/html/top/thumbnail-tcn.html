縮略圖顯示功能

縮略圖表示功能，使用中的資料夾內有圖片時，為了便於管理您可以把圖片登錄為該資料夾內文件的縮略圖。
資料夾公開功能有效並且縮略圖顯示功能開啟時，資料夾公開時，公開的資料夾內如有帶縮略圖的文件，可以連同縮略圖發送給指定用戶。
共用資料夾不具備資料夾公開功能，不能連同縮略圖發送。請注意！（→組共用功能）

接收人可以把分發資料夾的內容用縮略圖來表示。為了資料夾的內容更直觀，請使用縮略圖圖片。
而且，把資料夾內的文件作為縮略圖使用的圖片檔案，不可以利用公開檔案夾功能分發。請注意。

另外，分發単個帶縮略圖的檔案時，接收人將看不到“帶縮略圖”的顯示。請注意。

文件名變更和指定縮略圖的按鈕。
需要變更文件名請先輸入新文件名點擊[確定編輯]按鍵。（→關於文件一覽）
資料夾公開功能為有效，縮略圖功能開啟時，可以登錄或編輯縮略圖。要指定縮略圖請選擇您想要顯示的縮略圖。
表示設有縮略圖的文件。
點擊顯示所設定的縮略圖。
表示文件沒有設定縮略圖。
顯示縮略圖 顯示可否顯示縮略圖。
顯示縮略圖：ON 資料夾公開功能為有效，設有縮略圖顯示功能的狀態。公開資料夾時，可以將指定文件顯示為縮略圖發送。
顯示縮略圖：OFF 資料夾公開功能為有效，沒有設定縮略圖顯示功能的狀態。公開資料夾時，不能將指定文件顯示為縮略圖。
