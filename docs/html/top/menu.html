メニュー

ユーザ画面のメニューです。

ロゴ WebFileのロゴです。
お知らせ WebFileの使い方や新機能などのお知らせを確認できます。
ヘルプ 現在操作をしている画面のヘルプページが開きます。
サポート 専用のサポートへ、問合せのメールを送信します。
ファイル一覧 アップロードしたファイル一覧です。
ファイルの配布やフォルダ移動など、アップロードしたファイルの操作を行います。
引取り(収集) 収集したファイル一覧です。
ファイルの引取りや、ファイルのファイル一覧への保存など、引取ったファイルの操作を行います。
一斉配信
(※オプション)		 一斉配信の一覧です。
宛先ファイルのインポートを使ったメール一斉送信や一斉配信の履歴確認など、一斉配信の操作を行います。
一斉収集
(※オプション)		 一斉収集の一覧です。
CSV形式の宛先ファイルを使ったファイルの一斉収集や、一斉収集の履歴確認など、一斉収集関連の操作を行います。
待機メール一覧 送信待機メールの一覧です。
アドレス帳 アドレス帳の管理を行います。
上長承認一覧
(※オプション)		 上長の承認待ちメールや承認済み、却下済みの一覧です。
履歴 ユーザの操作履歴や、ファイルの履歴の一覧です。
設定 使いやすくするための設定ができます。テンプレートや署名を編集することができます。

アカウント名にカーソルを当てると、サブメニューが開きます。

プロフィール ユーザのプロフィールです。登録されている名前やメールアドレスを確認できます。
パスワード変更 パスワードを変更できます。
ログアウト ログアウトします。
