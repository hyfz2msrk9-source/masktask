组共享功能

组共享功能是在组所属的用户间可以共享文件的功能。

在管理者正使设定有效的时候,共享文件的上载用户被表示。
文件夹权限 拥有所有权限和组成员的管理权限的用户会显示在共享文件夹内。(→文件夹权限编辑)
上传用户 在管理者正使设定有效的时候，共享文件的上传用户被表示。
带锁下载 选项（※收件人姓名、地址模式）及文件夹加密功能有效时将显示，请点击。点击后将不可以上传相同文件夹名的文件夹，及不可以编辑加密文件夹。(→加密下载）

每个组都有专用的共享文件夹，有复数的所属用户。在组专用的共享文件夹内的文件供所属用户们共享。所属的用户设有权限，分为只读权限、读写权限、读写加文件夹操作权限的3种。 (→关于权限）

在组专用的共享文件夹内实行文件删除或文件的文件夹间移动，收到文件发送通知的人就无法再下载此文件。如果发送文件到组内的用户退出该组，接到文件发送通知的人也无法下载此文件。请注意。
另外，共享文件夹不能使用文件夹公开功能（→文件夹公开功能）。请注意。

在组所属用户的文件一览中的文件夹一览中会显示▼共享文件夹、▼个人文件夹。

共享文件夹
这里显示的文件夹是共享文件夹。
在所设定的组中可以共享文件。在组中的主文件夹是不能做成、编辑或删除的。
个人文件夹
这里显示的文件夹是个人用文件夹。可以自由地新建、编辑或删除。

文件夹权限编辑

每个组设置有组管理员。
组管理员是拥有所有权限和组成员管理权限的用户。选择共享文件夹会显示[文件夹权限]。

点击[文件夹权限]显示文件夹权限页面，只有组管理员能够设置用户权限及在组内追加用户或部门。

关于权限的显示
只读
把该用户权限设置为只读。
读写
把该用户权限设置为读写。
读写+文件夹操作
把该用户权限设置为读写及文件夹操作。
无
该用户没有权限。
删除
把该用户从组里删除。
文件夹权限信息 可以查看该用户所属的组和文件夹信息。
切换文件夹名称或建立子文件夹时，可以切换成用户所属的其它群组的信息。

组管理员以外的用户只显示文件夹信息和用户权限信息。
编辑 可以编辑所属用户的权限。
点击选择想要编辑的用户。

选择用户后点击[编辑]按钮，显示编辑画面。
请选择合适的权限。如果想把文件夹内的子文件夹也设置同样的权限，请在子文件夹也更新里打钩。
确定变更的内容后请点击[变更]按钮。
一起编辑 可以一起编辑所属用户的权限。
点击[一起编辑]按钮进入一起编辑画面。

请选择合适的权限。如果想把文件夹内的子文件夹也设置同样的权限，请在子文件夹也更新里打钩。
确定变更的内容请点击[一起变更]按钮。
用户追加 可以追加用户到组里。
点击[用户追加]按钮进入用户追加画面。

请在查找栏里查找想要加到组里的用户。查找时只能查找邮箱地址或账号完全一致用户。（→用户查找） 如果想把文件夹内的子文件夹也设置同样的权限，请在子文件夹也更新里打钩。 确定变更的内容请点击[追加]按钮。

加密下载

加密下载：选项（※覆盖模式）及文件加密功能有效时，下载文件时将同时对此文件进行加密。
加密后，将不可变更文件夹，除进行加密操作的用户外其它用户将不可操作，不可以上传同名文件夹。只允许进行加密操作的用户删除此文件。
另外，权限为只读的用户的页面，将不显示“带锁下载”按键。

鼠标移至「带锁」的图标处，可以确认给文件加锁的用户。

当给文件加锁用户以外的用户上传与带锁文件同文件名的文件时，上传会自动中止。

当给文件加锁的用户，上传与带锁文件同文件名的文件时，锁会自动解除。

共享文件夹的有效期限

管理方可以设定共享文件夹的有效期限。
共享文件夹被设定有效期限时，文件夹名旁会显示有效期限。


被设定有效期限的共享文件夹在有效期过后，根据管理方的设定，用户页面有以下3种显示方式。
管理方的设定 用户页面
隐藏文件夹 该共享文件夹将不被显示。
文件夹及文件的操作不可 可以看到共享文件夹但是无法对文件进行操作。
只允许下载和发送 只能实行下载和发送。
