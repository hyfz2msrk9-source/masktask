About Shortcuts and Right-Click Functions

About Shortcuts

The available keyboard shortcuts are as follows:

Shortcut Action
command/ctrl + a Select all files
After selecting a file, shift + click Selects the range up to the shift-clicked file
command/ctrl + click Select/Deselect multiple files individually
command/ctrl + c Copy file names (tab-separated)

About Right-Click Functions

When multiple files are selected and even one of them includes a file you do not have permission to operate.
As shown below, the operation items will be disabled and cannot be clicked.
