File list

Upload files

You can upload files directly by drag & drop on the file list screen (→File upload (Drag & Drop)).
If you want to set notifications to shared group members or add a memo when uploading, please click the [Upload] button on the file list.

Form to upload file is appear. Please select files and click [Upload].

[Add another file] Please select files you want to upload with [Add another file] button.
The Choose File to Upload dialog opens when you click the [Add another file] button.

Please check the screen the maximum number of file and the maximum upload capacity.

When you upload a file, it may be filtering according to the form of a file.
Please Ask an administrator about a file format.
[Delete] After you select the file you want to upload, you can delete the file that you do not want to upload.
Select upload
destination folder		 You can select folder you want upload files in.
Memo You can note down something here. And you can see this memo in the file details area.
It is not able to the person whom you sent these files to see this memo.

File uploading was completed.

If file sanitization is enabled, the file will be automatically sanitized when you click the [Upload] button.(→Sanitization)

To notify people of the uploaded file, click the [Distribute File] button. The Notification of registered file page will appear. (→File distribute)

About about upload file selection.

Select multiple files.
You can upload multiple files.Please select files at press Ctrl key or Shift key.
Drag and Drop File Upload.
You can drag and drop file uploads.
Drag and Drop Folder Upload.
You can drag and drop folder uploads. Please select folder that include files.

About virus scanning for file uploads.

Virus scanning is only performed on files that are less than MB.
Files larger than MB will be uploaded without being scanned.

About uploading shared folder.

If you choose to upload files to a shared folder, You can send notification E-mail to members of the group.
And you are able to edit the subject and body of the notification e-mail.

Select upload
destination folder		 If after selecting a shared folder, and if you go to the upload page, it is not possible to change the "upload folder". Please go to the file list page, and selecting shared folder.
notification by mail You can send notification E-mail to members of the group. Please select from all members or choice member.
Please click on the [>>Select a member] to show the members list. Select members from the member list.
notification by mail edit You can edit the subject and body of the e-mail notification when you click the Edit button.
After editing, please click the "Edit" button.
