資料夾公開功能

資料夾公開功能是，包括用戶所作成的個人資料夾裡的文件一起送信的功能。
可以把新建的資料夾整個送信給指定用戶。
共用資料夾不具有資料夾公開功能。請注意。
當縮略圖顯示功能開啟時，如果您公開的個人資料夾內有帶縮略圖的文件，您可以把縮略圖一起發送給指定用戶。收信方可以在收到的資料夾上看到附帶的縮略圖。為了讓資料夾裡的內容更明瞭請附加明瞭的縮略圖。
並且，資料夾內的文件如果是使用了縮略圖的圖片文件，則不能利用資料夾公開功能發送，請注意！
資料夾公開功能可以每次設置安全性設定。根據需要公開的情況可以各種各樣的安全性設定，確保了高安全性。

請在文件一覽裡選擇想要公開的資料夾，點擊頁面右側的[資料夾公開]按鈕。

移動到登錄文件的通知頁面。
輸入專案、選擇、根據情況設定安全性設置。

[從自己的郵箱發送] 用自己的郵箱發送資料夾公開的通知。
(→從自己的郵箱發送)
收件人 輸入收件人或從地阯簿添加。最多可以設置10個項目。（號碼可能已被管理員更改，詳情請聯係管理員。）
輸入收件人，然後單擊[追加收件人]按鈕。或者，單擊[>>從郵箱地址簿裡選擇]從您的地阯簿添加。
要刪除添加的收件人，請單擊每個收件人右側的[×刪除]按鈕。


在郵箱地址簿裡選擇的畫面中，從郵箱地址簿一覽表中點擊選擇或者打鉤選擇您要添加的郵箱地址，然後點擊[↓]按鈕就追加完畢了。

郵箱地址沒有問題的話請點擊[追加收件人]按鈕。
追加郵箱地址到文件發送頁面裡。

收件人中有未曾登錄過的郵箱地址時，在文件登錄完畢的通知頁面裡可以追加該郵箱地址到郵箱地址簿。
（會登錄在「未分類」群裡。→更改郵箱地址組裡進行群設置。）

如果郵件地址已經登記、向輸入候被郵件地址，地址簿就預測。
單擊輸入的郵件地址。單擊的郵件地址的地址被表示。

此外，如果您在郵件地址輸入字段中輸入多個由逗號（,）分隔的電子郵件地址，或者輸入名稱為名稱<郵件地址>的郵件地址，則可以添加可以自動添加的“名稱” 我們可以檢測候選人的“郵件地址”並添加選中的郵件地址。
公開資料夾名 發送的資料夾。可以把資料夾裡的內容一起發送。
這裡不能變更其他資料夾或追加其他資料夾。請注意。
寄件者 可以根據情況變更發送人及發送人郵箱地址來發送郵件。可以在(→寄件者設定)裡進行發送人的登錄。
寄件者設定功能為無效時不顯示寄件者。
郵件件名 郵件的件名。
郵件正文 郵件的正文。請輸入必填專案。(→關於郵件正文)
安全性設定 安全設置。請按照您的需要設定安全設置。(→關於資料夾公開的安全性設置)
字符編碼 妳能選擇文字編碼。

您輸入的內容沒有問題的話,請點擊[確認郵件]按鈕。
移動到登錄文件的資料夾公開（確認）頁面。

管理員設置上級時(*可選設定),在確認頁面上, 還將顯示“上級信息”或“選擇上級”區域。 如果顯示“選擇上級”區域,請選擇上級以請求批准。 批准請求電子郵件到達上級。
獲得上級許可後,發送資料夾公開的通知。如果上級駁回,則不發送。 您可以在上級確認一覽中查看批准狀態。(→上級確認一覽)

確認輸入、設定的內容無誤後,請點擊[發送郵件]按鈕。

移動到登錄文件的通知（完成）頁面。資料夾公開成功。

關於資料夾公開的安全性設置

通過SSL通信進行加密
通過EVSSL進行通信加密。基本功能(※ 只有SSL通信時顯示)。
資料夾公開的有效期限
設定公開資料夾的下載有效期限。超過有效期限後無法下載。
不加鎖
不設定密碼鎖。
設置臨時密碼鎖
設置臨時密碼。採用限定郵箱地址的臨時密碼，確保了高安全性。
設置指定密碼鎖
使用者可以自由指定密碼。請告知收件人指定的密碼。
開封確認
有人點擊下載URL就會把開封通知郵件到用戶。
下載確認
文件被下載後會聯繫用戶下載通知。

關於公開資料夾資訊

在文件一覽裡選擇想要發送的資料夾，點擊畫面右側的[資料夾公開信息]按鈕。

公開資料夾資訊裡顯示現在的公開資料夾的狀況。

收件人 將顯示把資料夾公開的分發人的郵箱地址及姓名。
發送日期〜有效期限 顯示發送開始日期到有效期限。
密碼 顯示資料夾公開時的密碼設置頁面。
關於密碼
無 選定“不加密”時顯示。
一次性（臨時） 選定“一次密碼加密”時顯示。
使用者可以通過鍵入指定的密碼，變更原密碼。
可以中止資料夾的公開。
