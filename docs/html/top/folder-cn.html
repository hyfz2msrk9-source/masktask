文件夹公开功能

文件夹公开功能是，将包括用户所作成的个人文件夹里的文件一起送信的功能。
可以把所建的文件夹整个送信给指定用户。
共享文件夹不具有文件夹公开功能。请注意。
当缩略图显示功能开启时，如果您公开的个人文件夹内有带缩略图的文件，您可以把缩略图一起发送给指定用户。
收信方可以在收到的文件夹上看到附带的缩略图。为了让文件夹里的内容更明了请附加明了的缩略图。
并且，文件夹内的文件如果是使用了缩略图的图片文件，则不能利用文件夹公开功能发送，请注意！
文件夹公开功能可以每次设置安全性设定。根据需要公开的情况，可以进行各种各样的安全性设定，确保了高安全性。

请在文件一览里选择想要公开的文件夹，点击页面右侧的[文件夹公开]按钮。

移动到登录文件的通知页面。
输入项目、选择、根据情况设定安全性设置。

[从本管理器发送] 用自己的邮箱发送文件夹公开的通知。
(→从本管理器发送)
收件人 输入收件人或从地址簿添加。最多可以设置10个项目。（号码可能已被管理员更改，详情请联系管理员。）
输入收件人，然后单击[追加收件人]按钮。或者，单击[>>从邮箱地址簿里选择]从您的地址簿添加。
要删除添加的收件人，请单击每个收件人右侧的[×删除]按钮。


在邮箱地址簿里选择的画面中，从邮箱地址簿一览表中点击选择或者打钩选择您要添加的邮箱地址，然后点击[↓]按钮就追加完毕了。

邮箱地址没有问题的话请点击[追加收件人]按钮。
追加邮箱地址到文件发送页面里。

收件人中有未曾登录过的邮箱地址时，在文件登录完毕的通知页面里可以追加该邮箱地址到邮箱地址簿。
（会登录在「未分类」群里。→更改邮箱地址组里进行群设置。）

如果邮件地址已经被登记的话，向输入时邮件地址，被地址簿预测。
单击输入的邮件地址。单击的邮件地址地址被表示。

此外，如果您在邮件地址输入字段中输入多个由逗号（,）分隔的电子邮件地址，或者输入名称为名称<邮件地址>的邮件地址，则可以添加可以自动添加的“名称” 我们可以检测候选人的“邮件地址”并添加选中的邮件地址。
共享文件名 发送的文件夹。可以把文件夹里的内容一起发送。
这里不能变更其他文件夹或追加其他文件夹。请注意。
发件人 可以根据情况变更发送人及发送人邮箱地址来发送邮件。可以在(→设定发送人)里进行发送人的登录。
发件人设定功能为无效时不显示发件人。
邮件件名 发送文件时送信邮件的件名。
邮件正文 发送文件时送信邮件的正文。请输入必填项目。(→关于邮件正文)
安全性设定 发送文件时的安全设置。请按照您的需要设定安全设置。(→关于安全设置)
字符编码 你能选择文字编码。

您输入的内容没有问题的话,请点击[邮件确认]按钮。
移动到登录文件的通知（确认）页面。

管理员设置上级时（*可选设定）,在确认页面上, 还将显示“上级信息”或“选择上级”区域。 如果显示“选择上级”区域,请选择上级以请求批准。 批准请求电子邮件到达上级。
获得上级许可后,发送资料夹公开的通知。如果上级驳回,则不发送。 您可以在上级确认一览中查看批准状态。(→上级确认一览)

移动到登录文件的通知（完成）页面。文件夹公开成功。

关于文件夹公开的安全性设置

通过SSL通信进行加密
通过EVSSL进行通信加密。基本功能(※ 只有SSL通信时显示)。
文件夹公开的有效期限
设定公开文件夹的下载有效期限。
超过有效期限后无法下载。
不加锁
不设定密码锁。
设置临时密码锁
设置临时密码。采用限定邮箱地址的临时密码，确保了高安全性。
设置指定密码锁
用户可以自由指定密码。请告知收件人指定的密码。
开封确认
文件发送后，有人点击下载URL就会给用户发送开封通知邮件。
下载确认
文件发送后，文件被下载后会给用户发送下载通知邮件。

关于公开文件夹信息

在文件一览里选择想要发送的文件夹，点击画面右侧的[公开文件夹信息]按钮。

公开文件夹信息里显示现在的公开文件夹的状况。

收件人 将显示文件夹公开给的收件人的邮箱地址及姓名。
发送日期〜有效期限 显示发送开始日期到有效期限。
密码 显示文件夹公开时的密码设置页面。
关于密码
无 选定“不加密”时显示。
一次性（临时） 选定“一次密码加密”时显示。
用户可以通过键入指定的密码，变更原密码。
可以中止文件夹的公开。
