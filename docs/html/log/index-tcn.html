共用組裡的文件操作記錄CSV檔案下載

在共享小組的文件操作履歷畫面可以以CSV形式下載共享小組對數(記錄)的。請選擇與小組名下載的履歷的日期。
選擇後全部，單擊[CSV下載]按鈕的話共享小組對數(記錄)被下載。

只有管理員的共有組才可以下載共享日誌。
