History

You can see the history of operation in this system.
If you use shared folder option, when you push [The history of shared group] button, you can see the history of shared group.

Please click Menu:History.

History of your operation is below.

[The history of shared group] Only when you use shared folder option, this button is displayed.
You can see the history about history of shared folder.
[The history of section group] Only when you use shared folder option, this button is displayed.
You can see the history about history of section folder.
File name This is the file name that you operated.
(If this operation does not have relation with file(ex, login ), in this area the operation will be displayed.)
Details of operation This is a detail of operation.
operation time This is the date that operation was done.
IP Address This is a remark about each operation.
Remark This is an IP-address of the computer in which operation was done.
If you send Email with SMTP, when the send error is occurred,the [resend] button is displayed.
When you push the [resend] button, mail distribution screen is displayed and the contents is same with that you set the contents. You can resend the Email with security settings.

The history list of shared group is below.

[the history of user] You can see the history about history of your personal folder.
[The history of section group] Only when you use shared folder option, this button is displayed.
You can see the history about history of section folder.
Group name This is the group name in which the operation was held.
User name This is the user name who done this operation.
File name This is the file name that you operated.
Details of operation This is a detail of operation.
Operation time This is the date that operation was done.
IP Address This is an IP address of the computer in which operation was done.
Remarks This is a remark about each operation.

[the history of user] You can see the history about history of your personal folder.
[The history of shared group] Only when you use shared folder option, this button is displayed.

When you move your cursor on the right side of each title, so 「▼」mark will appear and pull-down menu appear from「▼」.
You can arrange your history list with this pull-down menu. When you check the each item, the item is shown in the list, and you don’t check, the item is not shown in the list.

When you click the title of “Operation time”, the list will be ordered with ascending order or descending-order.
