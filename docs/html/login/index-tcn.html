登錄與認證

登錄畫面及可用操作會因您的環境而異。


要登錄WebFile，請使用以下任一認證方式：

帳號登錄（帳號・密碼）
Google SSO身份驗證
[##SAML_NAME##]
Windows綜合驗證
用戶身分驗證（證書）

共通操作

登錄

進入登錄畫面，根據認證方式登錄。認證後會跳轉到檔案一覽頁面。

退出

點擊選單中的「退出」即可登出並返回登錄畫面。

忘記帳號或密碼時

若忘記登錄資訊，請輸入註冊信箱並點擊「登錄資訊再發行」按鈕。
※使用Google SSO身份驗證或[##SAML_NAME##]的用戶無法重新發布密碼。

各認證方式詳細說明

帳號登錄（帳號・密碼）

依照畫面指示輸入帳號及密碼登錄。

雙因素認證（選用）

啟用雙因素認證時，帳號登錄後需透過認證App或郵件輸入驗證碼。
※使用Google SSO身份驗證或[##SAML_NAME##]的用戶無法使用WebFile的雙因素認證。

使用認證App
輸入驗證碼後點擊「確認」。可選擇一段時間內免認證。
使用郵件
輸入郵件中的驗證碼後點擊「發送」。可重新發送驗證碼。

Google SSO身份驗證

啟用Google SSO身份驗證時，請點擊「Google登錄」按鈕。

出現Google登錄畫面後，選擇帳號並輸入密碼即可登錄WebFile。

[##SAML_NAME##]認證

點擊[SAML登錄]按鈕，在服務登錄畫面輸入必要資訊後登錄。認證後進入WebFile。

Windows綜合驗證

AD用戶點擊「Windows綜合驗證」按鈕後，下次起會自動跳轉到認證畫面。

用戶身分驗證（證書）

用戶身分驗證是透過用戶端證書識別用戶的選用功能。
使用證書登錄時，請依下列步驟操作：

1. 雙擊證書檔案，開啟匯入畫面。


2. 選擇要匯入的檔案，點擊「下一步」。

3. 輸入密碼，點擊「下一步」。


如有需要，請勾選下列選項：

啟用加強私密金鑰保護
勾選後，每次登錄使用私鑰時都會提示確認。
將這個金鑰設成可匯出
勾選後，可匯出私鑰。
包含所有延伸內容
勾選後，包含所有擴充屬性。

4. 出現憑證存放區畫面時，按需設定後點擊「下一步」。

自動根據憑證類型來選取憑證存放區
如需自動放置憑證，請選擇此項。
將所有憑證放入以下的存放區
如需指定憑證存放位置，請選擇此項。

5. 匯入完成後，點擊「完成」關閉嚮導。

6. 下次登錄時會出現憑證選擇畫面，選擇憑證即可登錄。
