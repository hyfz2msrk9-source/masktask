ログイン

ログインエラー

ログインに失敗したときにエラーメッセージが表示されます。
そのエラーの内容と対応方法です。

通常表示されるエラー
アカウントまたはパスワードが正しくありません。
入力したアカウント、またはパスワードが間違っている場合に表示されます。
このアカウントは有効期限が切れています。
各アカウントに有効期限が設定されている場合、有効期限の終了したアカウントはログインできません。
再度ログインする必要がある場合は、管理者に問い合わせてください。
このアカウントはまだ有効ではありません。
各アカウントに有効期限が設定されている場合、有効期限前のアカウントはログインできません。
今すぐログインする必要がある場合は、管理者に問い合わせてください。

AD(ActiveDirectory)サーバと連携している場合に表示されるエラー

AD(ActiveDirectory)サーバとは、ユーザ管理を行うサーバです。
システムはActive Directoryサーバと提携してユーザを認証します。

ADサーバに接続できませんでした。
管理者にお問い合わせください。
システムサーバから、AD(Active Directory)サーバへの接続ができません。
アカウントまたはパスワードが正しくありません。
AD(Active Directory)認証においてID/PWが間違っています。
もしくは、システムの設定が間違っているため、認証に失敗しています。
ADアカウントにロックがかかっています。
管理者にお問い合わせください。
AD(Active Directory)サーバのアカウントにロックがかかっています。管理者に問い合わせてください。
ADアカウントが無効になっています。
管理者にお問い合わせください。
AD(Active Directory)サーバのアカウントが無効になっています。管理者に問い合わせてください。
ADアカウントにシステムへのログイン権限がありません。
管理者にお問い合わせください。
このアカウントは、AD(Active Directory)サーバでシステムへのログインが許可されていません。管理者に問い合わせてください。
システムアカウントの初期化に失敗しました。
登録可能ユーザ数を超えています。
管理者にお問い合わせください。
アカウント数が契約ユーザ数を超えるため、ログインできません。
管理者に問い合わせてください。
システムアカウントの初期化に失敗しました。
システムの容量が不足しています。
管理者にお問い合わせください。
容量が足りないためログインができません。管理者に問い合わせてください。
システムアカウントの初期化に失敗しました。
ADアカウントのユーザ情報が不足しています。
（表示名、メールアドレスが必要です）
管理者にお問い合わせください。
AD(Active Directory)アカウントのユーザ情報が不足しているため、ログインできません。管理者に問い合わせてください。
システムアカウントの初期化に失敗しました。
ADアカウントのメールアドレスが他のアカウントのメールアドレスと重複しています。
管理者にお問い合わせください。
AD(Active Directory)アカウントのメールアドレスが、他のアカウントのメールアドレスと重複しているため、ログインすることができません。管理者に問い合わせてください。
認証方式がGoogle SSO認証または[##SAML_NAME##]の場合に表示されるエラー
アカウントが登録されていません。
入力したアカウントが間違っています。
もしくは、システムの設定が間違っているため、認証に失敗しています。
ログイン情報の取得に失敗しました。
再度ログインを行なってください。
一時的にGoogle SSOまたは[##SAML_NAME##]サービスにて問題が発生しています。
もしくは、システムの設定が間違っているため、認証に失敗しています。
