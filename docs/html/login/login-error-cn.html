登录失败时会弹出错误信息。
出错内容及对应方法。

标准显示错误
账号或密码错误。
您输入的账号或密码有误时显示该信息。
此账号已过有效期。
如果账号设定有效期，有效期过后该账号将无法登录。
需要再次登录的用户请与管理员联系。
此账号还未生效。
如果账号设定有效期，在有效期生效前该账号无法登录。
需要马上开通登录的用户请与管理员联系。

AD(ActiveDirectory)服务器是用来管理用户信息的服务器。
系统会连接ActiveDirectory服务器来认证用户。
