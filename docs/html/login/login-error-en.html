Login Error

When you fail in log in, the error message is displayed.
The content and the coping process of the error are as follows.

Usual error
The account or the password is not correct.
When input account or password is wrong, the message is displayed.
This account expired.
When the expiration date is set to each account, as for the account that the expiration date ended, log in is not possible.
Please inquire of system administrator., if you want to log it in again.
This account is not effective yet.
When the expiration date is set to each account, the account before the expiration date is not able to log in.
Please inquire of system administrator if you want to log in at once.

Error displayed in case of cooperation with AD(Active Directory) server

The AD(ActiveDirectory) server is a server that manages users.
This system authenticates the user in cooperation with the Active Directory server.

The system failed in the connection of the AD server.
Please inquire of system administrator.
The system is not able to connect with the AD(Active Directory) server.
The account or the password is not correct.
Account (ID) and the password are wrong in the AD(Active Directory) attestation. Or, it fails in the attestation because the setting of the system is wrong.
The AD account has been locked.
Please inquire of system administrator.
The account of the AD(Active Directory) server is locked. Please inquire of system administrator.
The AD account has been disabled.
Please inquire of system administrator.
The account of the AD(Active Directory) server is disabled. Please inquire of system administrator.
The AD account has no login authority to system.
Please inquire of system administrator.
As for this account, the login to WebFile has not been permitted with the AD(Active Directory) server. Please inquire of system administrator.
Failed to initialize your account.
The number of users that can be registered is exceeded.
Please inquire of system administrator.
Because the number of accounts exceeds the number of contract users, log in cannot be done.
Please inquire of system administrator.
Failed to initialize your account.
The capacity of this system is insufficient.
Please inquire of system administrator.
Please inquire of system administrator.
Failed to initialize your account.
User information on the AD account is insufficient.
(Name and the Email address are necessary. )
Please inquire of system administrator.
Because user information on the AD(Active Directory) account is insufficient, you are not able to log in.
Please inquire of system administrator.
Failed to initialize your account.
The Email address of the AD account overlaps with other accounts.
Please inquire of system administrator.
Because the Email address of the AD(Active Directory) account overlaps with the Email address of other accounts, you are not able to log in.
Please inquire of system administrator.
