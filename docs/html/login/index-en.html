Login & Authentication

The login screen and available operations may differ depending on your environment.


To login to WebFile, use one of the following authentication methods:

Login with account (ID & password)
Google SSO authentication
[##SAML_NAME_EN##]
Windows Integrated Authentication
Client authentication (certificate)

Common Operations

Login

Access the login screen and login using the appropriate authentication method. After authentication, you will be redirected to the file list page.

Logout

Click "Logout" in the menu to logout and return to the login screen.

If you forgot your account or password

If you forgot your login information, enter your registered email address and click the [Reissue] button.
※Users using Google SSO authentication or [##SAML_NAME##] cannot reissue their password.

Details of each authentication method

Standard login account & password)

Follow the instructions on the screen and enter your account and password to login.

Two-factor authentication (optional)

If two-factor authentication is enabled, after logging in with your account, enter the verification code from an authentication app or email.
※Users using Google SSO authentication or [##SAML_NAME_EN##] cannot use two-factor authentication with WebFile.

Using an authentication app
Enter the code and click [Confirm]. You can skip two-factor authentication for a certain period by checking the box.
Using email
Enter the code from the email and click [Send]. You can resend the code if needed.

Google SSO authentication

If Google SSO authentication is enabled, click the "Sign in with Google" button.

When the Google login screen appears, select your account and enter your password to login to WebFile.

[##SAML_NAME##]

Click the [##SAML_BUTTON_NAME##] button, enter the required information on the service's login screen, and log in. After authentication, you will be logged in to WebFile.

Windows Integrated Authentication

AD users can click the "Windows Integrated Authentication" button to automatically transition to the authentication screen from next time.

Client authentication (certificate)

Client authentication is an optional feature that identifies users by client certificate.
To login using a certificate, please follow these steps:

1. Double-click the certificate file to open the import screen.


2. Select the file to import and click the [Next] button.

3. Enter the password and click the [Next] button.


If necessary, check the following options:

Enable strong private key protection
If checked, you will be prompted every time the private key is used for login.
Mark this key as exportable
If checked, you will be able to export the private key later.
Include all extended properties
If checked, all extended properties will be included.

4. When the Certificate Store screen appears, configure as needed and click the [Next] button.

Automatically select the certificate store based on the type of certificate
Select this if the certificate should be placed automatically based on its type.
Place all certificates in the following store
Select this if you need to specify the storage location for the certificate.

5. When the import is complete, click the [Finish] button to close the wizard.

6. The next time you login, a certificate selection screen will appear. Select your certificate to login.
