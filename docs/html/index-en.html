About this manual

This is an instruction manual for the system.
In this manual, characters in the “[]” are meaning the characters on the button.
According to your environment of your computer or your browser, the Font type or color may different from image of the screen in this manual.

About users

Users use the system.
Users are able to use the following function: distribute files, collect files, set and use the address book, check the history, set ***, change the password in the profile area.
It is possible to deal with various users through these settings.

About initialize

The first time when you use the WebFile, you have to change your user password to another after you login the system.

Login

Please login the system. (→Login ).

Change user password

After you login the system, please click Menu: Profile and click the [Change password] button in the column password. After that, you change your user password. (→Change password)
