Address book

This is your address book. When you want to distribute or collect file, you can select the address that you want to send your file from the address book. You can enter the address easily without miss typing.

Please click Menu:Address book.

Address book

Please click Menu:Address book, the address list will appear.

On the left side, there is a list of groups. If you click a group, addresses that is belonging to the group will appear on the right.
The group that you see their addresses now have mark and its back color is different from others.
