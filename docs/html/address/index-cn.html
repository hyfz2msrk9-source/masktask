邮箱地址簿

是邮箱地址通讯录。邮箱地址登录到该通讯录后，发送文件或收集文件时，可以从通信录中直接选择邮箱地址，省去输入的麻烦。
菜单：请点击“邮箱地址簿”按键。

邮箱地址一览

目录：点击邮箱地址簿移动至邮箱地址簿页面。

左侧显示组一览。点击后根据所登录的组显示邮箱地址到右侧。
现在显示中的组背景颜色会变，并带有图标。()

使用CSV文件下载
邮箱地址		 使用CSV文件追加新邮箱地址。使用CSV文件下载邮箱地址(→从CSV文件追加、从CSV文件下载)
个人/共通/部门 您可以切换地址簿类型。
设定不显示共通时，显示共通以外的。
设定不显示部门邮箱地阯簿时，显示部门邮箱以外的。
设定不显示共通和部门邮箱时，只显示个人的。
如果选择部门邮箱地阯簿，显示每箇部门的组。
组的追加 显示组追加区。(→追加组)
邮箱地址的追加 显示邮箱地址追加区。(→追加邮箱地址)
邮箱地址编辑 从邮箱地址一览中选择想要编辑的邮箱地址后，显示邮箱地址编辑区。编辑邮箱地址只能是1个。(→编辑邮箱地址)
删除邮箱地址 在邮箱地址一览中选择想要删除的邮箱地址后，删除邮箱地址。(→删除邮箱地址)
更改组成员 表示登记的邮件地址从属于的小组。(→更改邮箱地址组)
如果选择部门邮箱地址簿，则还显示[复制到另一个部门组]按钮。(→复制到另一个部门组)
邮箱地址全删除 在邮箱地址一览中删除所有的邮箱地址。(→删除邮箱地址)
邮箱地址一览 表示登记的邮件地址一览。
名字（片假名） 邮箱地址所登录的人名（片假名）。点击标题可以按照人名来排列。
组 邮箱地址的分类组。点击标题可以按照组名来排列。
邮箱地址 邮箱地址。点击标题可以按照邮箱地址来排列。
