Delete address

Please click the address you want to delete in the address list.
You can select more than one address.
After selection please click [Delete address] button.

Confirmation message will appear, after confirm your operation, please click [OK] button.
The address you select will be deleted.

If you want to delete all addresses in your address list,please click the[Delete all addresses] button.
When you select the personal address list by [Personal/Common TAB], [Delete all personal addresses] button appears. and when you select the common addres list by [Personal/Common TAB],[Delete all common addresses] buton appears.

Confirmation message will appear, after confirm your operation, please click [OK] button.
The address you select will be deleted.
