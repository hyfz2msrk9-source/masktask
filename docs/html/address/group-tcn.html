郵箱地址簿

更改郵箱地址組

變更郵箱地阯從屬于的小組。選擇變更的郵件地阯，請單擊[更改組成員]按鈕。
選擇復/複數的郵件地阯的話，歸結能變更。

錶示更改組成員。請選擇小組單擊、[↓]按鈕。
錶示選擇為下部有的「組」的小組。做小組多選的話，郵箱地阯從屬于復/複數的小組。

「組」郵箱地阯地阯從屬于的小組。單擊[除外]的話，從「組」小組除外。「組」什麼都沒有的情況，成為「未分類」。
變更如果好，也請單擊[更改組成員身份]按鈕。小組的變更完成。

複製到另一箇部門組(※ 僅是部門郵箱地阯簿的功能)

如果您選擇部門郵箱地阯簿，顯示[複製到另一箇部門組]按鈕。

與更改郵箱地阯組的情況一樣，請選擇小組單擊、[↓]按鈕。
變更如果好，也請單擊[複製到另一箇部門組]按鈕。
如果選擇多箇部門組，則郵箱地阯添加到每箇部門組。

追加組

點擊在組一覽下部的「追加組」按鈕。

在組一覽中會顯示新的組輸入欄。

輸入組名後，點擊（保存）按鈕。
要取消輸入時，點擊（取消）按鈕。

編輯組

點擊組一覽裡各個組旁邊的（編輯）按鈕。

該組名會顯示為編輯狀態。

編輯組名後點擊（保存）按鈕。
要取消編輯時請點擊（取消）按鈕。

刪除組

點擊在組一覽裡的各個組旁邊的（刪除）按鈕。

系統會顯示組刪除確認資訊，如果沒有問題請點擊[OK]按鈕。
所選擇的組會被刪除。被刪除的組內的郵箱地址會移動至未分類。

變更組的排列順序

滑鼠拖動組名，按照想要排列的順序拖動就可以變更組的排列順序。
把滑鼠移動到想要變更順序的組名上。

拖動滑鼠至想要變更到的位置。
