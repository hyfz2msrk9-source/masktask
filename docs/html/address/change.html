CSVファイルでダウンロード

選択後、[アドレス編集]ボタンをクリックしてください。

アドレス帳編集エリアが表示されます。編集を行い、[変更]ボタンをクリックしてください。

アドレスの削除

アドレス一覧より削除を行うアドレスをクリックし、選択してください。
アドレスは複数選択可能です。
選択後、[アドレス削除]ボタンをクリックしてください。

確認メッセージが表示されますので、よろしければ[OK]ボタンをクリックしてください。
選択したアドレスが削除されます。

アドレス一覧にあるアドレスを全て削除する場合は、[アドレス全削除]ボタンをクリックしてください。
「個人／共通タブ」で個人を選択されている場合は[個人アドレス全削除]、共通を選択されている場合は[共通アドレス全削除]と表示されます。

確認メッセージが表示されますので、よろしければ[OK]ボタンをクリックしてください。
選択したアドレスが削除されます。
