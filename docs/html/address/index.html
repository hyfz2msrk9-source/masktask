アドレス帳

アドレス帳では、宛先の登録や編集、削除の操作ができます。
アドレス帳に宛先を登録しておくことで、ファイルの配布や収集時に入力の手間を省くことができます。

メニュー：アドレス帳をクリックしてください。

アドレス帳一覧

メニュー：アドレス帳をクリックすると、アドレス帳一覧画面へ遷移します。

左側にグループ一覧を表示しています。クリックすると、登録されたグループごとのアドレスが右側に表示されます。
現在表示しているグループは、背景色が変わり、マークが付きます。

[検索]ボタン ：検索を開始します。
[クリア]ボタン ：検索を解除します。
