上传文件

收到接收文件的请求邮件后，可在WEB系统上传文件，并发送给对方。
(→接收（收集）)

标准上传

收到数据发送请求邮件，使用邮件里的上传用URL链接进行数据上传。
点击访问邮件里的上传URL链接。

在上传页面里进行文件上传。
点击[文件追加]按钮选择想要上传的数据，点击[上传]按钮完成上传。

[文件追加] 使用[文件追加]请选择你要上传的文件。
在选择要上传的文件对话框打开时，单击[添加文件]按钮。
[删除] 删除所选文件。
给发件人的信息 文件上传的同时，可以给对方发送信息。
[上传] 完成文件上传。
您可以通过拖放选择文件夹
在Edge、Google Chrome、Firefox和Safari中,可以通过从资源管理器（Mac上的Finder）拖放来选择文件夹。
