収集メールを受け取った方（アップロード）

ファイルのアップロード

指定パスワードを求められる場合

あらかじめ送信者によって指定されたパスワードを解除し、アップロード画面を開きます。
メールアドレスの入力ではなく、いきなりパスワードを要求される場合は、メールの送信者が指定した固定パスワードが設定されています。
パスワードが不明な場合は、メールの送信者まで、ご確認ください。

メールや電話等で、メールの送信者から案内されたパスワードを入力します。


例）パスワードをメールで案内された場合

正しいパスワードを入力した場合
ファイルのアップロード画面へのリンクが表示されます。
[ファイルアップロード]をクリックすると、アップロード画面に遷移し、アップロードが可能です。
誤ったパスワードを入力した場合
エラーメッセージが表示され、アップロード画面に進めません。
