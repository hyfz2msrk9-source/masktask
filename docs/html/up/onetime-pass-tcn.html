遇到要求輸入臨時密碼時

領取臨時密碼（使用一次後，不能再用第二次的密碼形式），密碼解鎖後進行上傳。
需要領取密碼時，請輸入收到郵件的人的郵箱地址。
如果輸入其他人的郵箱地址，或把郵件轉發後輸入轉發收件人的郵箱地址是無法收到密碼的。如果遇到這種情況請輸入最初收到郵件的人的轉發前的郵箱地址。

用「○○＠sample.co.jp」的郵箱地址收信，自動轉發給「▲▲@mailaddress.com」並確認過郵件的，請輸入「○○＠sample.co.jp」的郵箱地址。

輸入郵箱地址後點擊[領取密碼]按鈕。

輸入正確的郵箱地址
系統會把密碼以郵件的形式發送到輸入的郵箱地址裡，打開密碼輸入頁面。
輸入錯誤的郵箱地址時
系統會提示錯誤資訊，無法進入密碼輸入頁面。

輸入正確的郵箱地址後，輸入的郵箱地址會收到件名為「文件上傳用密碼的通知」的郵件。
把郵件內的密碼輸入到密碼發送頁面內的密碼欄裡，點擊「發送」按鈕。

輸入正確的密碼
顯示文件的上傳頁面的連接。
點擊 [文件上傳]移動至上傳頁面，可以進行上傳。
輸入錯誤的密碼
系統顯示錯誤提示，無法進入上傳頁面。
