収集メールを受け取った方（アップロード）

ファイルのアップロード

ファイルの引き取り依頼メールを受け取ったとき、Web上のシステムにファイルをアップロードし、相手にファイルを送ることができます。 (→引取り(収集))

通常アップロード

データの送信依頼メールを受け取り、メールに記載されているアップロード用URLからデータをアップロードします。
メールに記載されている、アップロードURLへアクセスします。

アップロード画面から、ファイルをアップロードします。
[ファイル追加]ボタンでアップロードしたいデータを選択し、[アップロード]ボタンを押せば、アップロード完了です。

[ファイル追加] アップロードしたいファイルを選択します。[ファイル追加]ボタンをクリックするとファイル選択ウィンドウが開きますので、ファイルを選択してください。
[削除]ボタン 選択したファイルを削除します。誤って選択した場合にご利用いただけます。
差出人宛のメッセージ ファイルをアップロードすると同時に、相手にメッセージを送信することができます。
[アップロード]ボタン ファイルのアップロードを完了します。
ドラッグ＆ドロップでフォルダごとファイルをアップロード
Edge、Google Chrome、Firefox、Safariをご利用の場合は、エクスプローラー（Macの場合はFinder）からドラッグ＆ドロップでフォルダを選択することが可能です。
アップロードしたいファイルが入っているフォルダを選択し[ファイル追加]ボタンにドラッグ＆ドロップしてください。
