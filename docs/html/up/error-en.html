In case you cannot upload files

If the messages as follows are displayed, you cannot upload files. Please ask for sender the Email and files.

This demand was deleted by sender.
You cannot upload files because the request is canceled by the sender.
This file's upload expiry date has passed.
You cannot upload files because the file’s upload expiry date has passed.
The URL is incorrect.
You cannot upload files because the URL to upload files that is inform you is incorrect and you cannot access the upload screen.
Can't upload a file.Because this folder does not have capacity.
You cannot upload files because the folder that you try to upload into have no enough capacity.
Failed to sanitize the file / cannot be sanitized
When the sanitize option is enabled, an error is displayed when a file that cannot be sanitized is uploaded.
