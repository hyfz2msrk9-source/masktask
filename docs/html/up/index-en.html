Upload files

When you get an Email that is inform you to collect files, you can upload your files to the system on the web, and the files are sent to the sender of the Email.
(→Receive (collect))

The ordinary upload

Please upload files with the URL that is written in the Email that is inform you to collect files.
First, please access to the URL written in the Email to upload files.

Please upload files in the upload screen.
Please click[Add another file]button and select the files you want to upload, and click [Upload] button. It is completed to upload files.

[Add files] Please select files you want to upload with [Add another file] button.
The Choose File to Upload dialog opens when you click the [Add another file] button.
[Delete] You can delete file name that is prepared for upload.
Message to sender You can send message to the sender at the same time to upload files.
[Upload] Complete to upload files..
Drag and Drop Folder Upload.
In Edge, Google Chrome, Firefox, or Safari, folders can be uploaded by drag and drop from Explorer (or Finder on a Mac).
Please select folder that include files.
