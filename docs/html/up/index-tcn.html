上傳文件

接收文件的接收申請郵件後，可在WEB系統上傳文件，併發送給對方。
(→接收（收集）)

標準上傳

收到資料發送請求郵件，使用郵件裡的上傳用URL連結進行資料上傳。
點擊訪問郵件裡的上傳URL連結。

在上傳頁面裡進行文件上傳。
點擊[文件追加]按鈕選擇想要上傳的資料，點擊[上傳]按鈕完成上傳。

[文件追加] 使用[文件追加]請選擇你要上傳的文件。
打開文件選擇窗口。請選擇一個文件。
[刪除] 刪除所選文件。
給寄件者的信息 文件上傳的同時，可以給對方發送資訊。
[上傳] 完成文件上傳。
您可以通過拖放選擇資料夾
在Edge、Google Chrome、Firefox和Safari中,可以通過從資源管理器（Mac上的Finder）拖放來選擇文件夾。
