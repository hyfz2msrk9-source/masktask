収集メールを受け取った方（アップロード）

ファイルのアップロード

アップロードできない場合

以下のような画面やメッセージが表示される場合は、ファイルのアップロードが出来ません。メールの送信者までお問合せください。

この要求は削除されています
送信者によって、アップロード依頼が削除されています。
収集有効期限を過ぎています
送信者が指定したアップロード期限を過ぎたため、アップロードできません。
URLが正しくありません
通知されたアップロードURLに誤りがあり、アップロード画面に正しくアクセスできません。
ファイルをアップロードするための空き容量が足りません
送信者側のファイルをアップロードするための空き容量が足りず、ファイルをアップロードできません。
ファイルの無害化に失敗しました。/無害化できません
無害化オプションがあり、無害化できないファイルをアップロードした際に表示されるエラーです。
