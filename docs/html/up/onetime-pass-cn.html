上传文件

遇到需要输入临时密码时

领取临时密码（使用一次后，不能再用第二次的密码形式），密码解锁后进行上传。
需要领取密码时，请输入收到邮件的人的邮箱地址。
如果输入其他人的邮箱地址，或把邮件转发后输入转发收件人的邮箱地址是无法收到密码的。如果遇到这种情况请输入最初收到邮件的人的转发前的邮箱地址。

用「○○＠sample.co.jp」的邮箱地址收信，自动转发给「▲▲@mailaddress.com」并确认过邮件的，请输入「○○＠sample.co.jp」的邮箱地址。

点击 [领取密码]按钮。

输入正确的密码
系统会把密码以邮件的形式发送到输入的邮箱地址里，打开密码输入页面。
输入错误的密码
系统显示错误提示，无法进入上传页面。

输入正确的邮箱地址后，所输入的邮箱地址里会收到件名为「上传用密码的通知」的邮件。
把邮件内的密码在密码发送页面里的密码栏中输入，点击 [密码发送]按钮。

输入正确的密码
显示文件的上传页面的连接。
点击 [文件上传]移动至上传页面，可以进行上传。
输入错误的密码
系统显示错误提示，无法进入上传页面。
