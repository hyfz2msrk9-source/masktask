アカウント設定

WebFileから初期設定ファイルをダウンロードして、シンクローラーのアカウント設定を行います。

メニュー：設定をクリックしてください。

：ダウンロードをクリックしてください。

[初期設定ファイル]をクリックしてダウンロードしてください。

を起動して初期設定ファイルの指定画面を表示し、ダウンロードしておいた初期設定ファイルを指定して[OK]ボタンをクリックします。

※既にアカウント設定が行われている場合は、初期設定ファイルの指定画面は表示されません。


WebFileのパスワードを入力し、[OK]ボタンをクリックします。

WebFileへのログインに成功すると、設定画面が表示されます。(→設定)
