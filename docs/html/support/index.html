よくあるお問い合わせ

よく頂くお問い合わせについてご紹介します。

ファイル配布時、「送信先メールアドレスが正しくありません」が表示される場合

ファイル配布時に、エラーメッセージ「送信先メールアドレスが正しくありません」が表示されたので、メールアドレスを修正しても、再び同じエラーメッセージ「送信メールアドレスが正しくありません」が出る場合があります。

送信先メールアドレスは、フォームに入力し[宛先追加]ボタンをクリックすると、フォームの下にメールアドレスが追加されます。
これは、メールアドレスをフォーム入力したままで[宛先追加]ボタンをクリックせず、フォームの下にある[メール確認]ボタンをクリックして頂いても、同じように追加されます。
エラーメッセージ「送信先メールアドレスが正しくありません」が表示され続けるときは、追加されている正しくないメールアドレスが削除されていない可能性があります。
削除したいメールアドレスの右にある[×削除]ボタンをクリックして、メールアドレスを削除してください。
