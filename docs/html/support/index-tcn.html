發郵件到技術支援

發送意見或提問到技術支援。

目錄：點擊支持。

輸入詢問內容，點擊[確認郵件]按鈕。移動至技術支援確認頁面。 確認內容無誤請點擊[發送郵件]按鈕發送郵件至技術支援。

常用提問

關於經常遇到的問題進行介紹。

文件發送時，顯示[收件人郵箱地址錯誤]

在文件發送時，可能會出現顯示[收件人郵箱地址錯誤]的錯誤提示，修改郵箱地址再次發送還是顯示[收件人郵箱地址錯誤]的情況。

請在表格內鍵入寄件者郵箱地址，並點擊“追加收件人”按鍵，則此郵箱地址成功保存在表格下麵。
在表格內鍵入郵箱地址後，可以不點擊“追加收件人”按鍵，點擊表格下面的“確認郵件”鍵，進行同樣的追加。
當多次顯示“寄件者郵箱地址有誤”的錯誤消息後，有可能對新增的錯誤郵箱地址進行刪除。
點擊想要刪除的郵箱地址右側的[×刪除]，刪除此郵箱地址。
