发邮件到技术支持

发送意见或提问到支持。

目录：点击技术支持。

输入询问内容，点击[邮件确认]按钮。移动至技术支持确认页面。
确认内容无误请点击[发送邮件]按钮发送邮件至技术支持。

常用提问

关于经常遇到的问题的介绍。

文件发送时，显示[收件人邮箱地址错误]。

在文件发送时，可能会出现显示[收件人邮箱地址错误]的错误提示，修改邮箱地址再次发送还是显示[收件人邮箱地址错误]的情况。

请在表格内键入发件人邮箱地址，并点击“追加收件人”按键，则此邮箱地址成功保存在表格下面。
在表格内键入邮箱地址后，可以不点击“新增收件人”按键，点击表格下面的“邮件确认”键，进行同样的追加。
当多次显示“发件人邮箱地址有误”的错误消息后，有可能对新增的错误邮箱地址进行删除。
点击想要删除的邮箱地址右侧的[×删除]，删除此邮箱地址。
