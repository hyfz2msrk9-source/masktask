管理者管理

登録されている管理者の一覧を表示します。また、管理者を管理する入り口となっています。
メニュー：ユーザ管理をクリックし、[管理者管理]ボタンをクリックしてください。

管理者管理画面へ遷移します。
管理者管理画面は、システム側で設定された内容によって画面が違う場合があります。
画面は、管理画面でできる操作が履歴の閲覧のみの画面と、管理者の追加、編集、削除、履歴の閲覧が可能である画面と2通りあります。

操作が履歴の閲覧のみの画面です。
履歴の機能については、管理者履歴をご覧ください。

管理者の追加、編集、削除、履歴の閲覧が可能である画面です。

備考

備考欄には、任意のメモや特記事項などを自由に入力することができます。

アカウントロック

アカウントロックは、設定が有効になっている場合のみ確認することができます。
管理者にアカウントロックがかかっている場合に、アカウントロックされていない別の管理者がログインし、管理者管理画面でアカウントロックされた管理者を確認することができます。

管理者権限

管理者権限はシステムの管理者の権限を表示しています。
各権限ごとに行える操作が制限されています。

管理者権限の移行について

>>全ての権限の移行
特定の管理者が管理しているユーザ・部署・グループを、別の管理者の管理下へ移行します。
権限の移行方法については、管理者編集をご覧ください。


>>ユーザの管理権限の移行
ユーザ情報の編集や削除操作を行える管理者を、他の管理者へ変更します。
ユーザ管理者が追加した特定のユーザのみ、別のユーザ管理者の管理下に変更したい場合などに有効です。
編集権限のある管理者を変更すると、対象のユーザのグループ・部署への所属情報、上長を設定していた場合は上長設定が、初期化されます。
管理者の変更方法については、ユーザ一覧の管理者の変更についてをご覧ください。
