アーカイブシステム(※オプション)

アーカイブ機能はオプション機能です。別途、お申込みが必要となります。
アーカイブ機能が有効でない場合は、メニューに「アーカイブシステム」が表示されません。

アーカイブ機能が有効な場合は、配布ファイルのダウンロード時、引き取りファイルのアップ
ロード時にファイルのアーカイブが作成されます。
アーカイブシステム画面では、アーカイブファイルのダウンロードやエクスポートができます。

アーカイブファイル一覧

保存されているアーカイブファイルの一覧を表示します。
条件を指定してアーカイブファイルの情報を絞り込んだり、絞り込んだファイルをエクスポートすることが可能です。

検索条件 アーカイブファイルの一覧を指定の条件で検索します。
アーカイブ作成日 アーカイブファイルが作成された日付を指定できます。
アカウント ファイルを配布(収集)したユーザのアカウントを指定できます。
ユーザ名 ファイルを配布(収集)したユーザの名前を指定できます。
メールアドレス ファイルを配布(収集)したユーザのメールアドレスを指定できます。
ファイル名 アーカイブファイルの名前を指定できます。
送信先 ファイルの配布先をを指定できます。
収集先 ファイルの引き取り(収集)先をを指定できます。
[検索] 指定された条件で、アーカイブファイルを検索します。
[クリア] 指定されている検索条件をクリアし、絞り込みを解除します。
アーカイブ種別 アーカイブファイルの分類です。
アカウント ファイルを配布(収集)したユーザのアカウントです。
ユーザ名 ファイルを配布(収集)したユーザの名前です。
メールアドレス ファイルを配布(収集)したユーザのメールアドレスです。
ファイル名 配布(収集)したファイルの名前です。
送信先 ファイルを配布した宛先です。
収集先 ファイルの引き取り(収集)を依頼した宛先です。
[詳細] ファイルを配布(収集)した際の詳細な内容を確認できます。
また、保存されているアーカイブファイルをダウンロードすることも可能です。

エクスポート

アーカイブファイルは、設定された期間毎に定期的にエクスポートされます。エクスポートを行う期間は、各種設定＞アーカイブに関する設定（→機能設定）で設定できます。

手動エクスポート

定期エクスポートのほか、条件を指定して、手動でエクスポートも可能です。
手動でエクスポートを行う場合は、エクスポートしたいファイルを一覧から検索し、[アーカイブファイルエクスポート]ボタンをクリックしてください。

エクスポートが完了すると、完了メールが指定のメールアドレスに送信されます。
完了メールを受け取るメールアドレスは、各種設定＞アーカイブに関する設定（→機能設定）で設定できます。

エクスポート ファイル一覧

[エクスポートファイル一覧]ボタンから、エクスポートされたファイルの一覧画面を開けます。


エクスポートファイル一覧画面では、必要なファイルをダウンロードしたり、不要になったファイルを削除できます。
