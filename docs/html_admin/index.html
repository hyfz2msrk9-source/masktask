本マニュアルについて

本マニュアルは、管理者側操作マニュアルです。
本マニュアル中の"[]"で囲まれた文字は、アイコンやボタンに表示されている文字を示しています。
本マニュアル中の画面イメージは、お使いのブラウザによって、フォントや色彩等が異なる場合があります。

管理者について

管理者は、管理者画面を利用します。
管理者画面では、ユーザの管理、テンプレートの編集、ログ管理、パスワード変更などを行うことができます。
設定により、様々な使い方に対応することができます。大変重要なユーザですので、定期的にパスワードの変更をしてください。
また、パスワードの管理にはお気をつけください。

初期設定について

システムを初めてご利用になる場合は、管理者のパスワードを初期パスワードからご変更ください。
また、利用するユーザをご登録ください。

ログイン

管理者画面にログインしてください。(→ログイン)

パスワードを変更する

メニュー：パスワード変更をクリックして、パスワードを変更してください。 (→パスワード変更)

ユーザを作成する

メニュー：ユーザ管理をクリックし、ユーザ管理画面を表示します。
[ユーザ追加]ボタンをクリックして、ユーザ管理＞ユーザの登録画面を表示させて下さい。
必要事項を入力し、ユーザを登録します。(→ユーザ追加)
登録したユーザ情報のアカウントとパスワードは、お手元にお控えください。
ユーザへ連絡する必要があります。
