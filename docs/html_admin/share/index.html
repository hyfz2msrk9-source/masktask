グループ共有機能(※オプション)

グループ共有機能は、グループに所属しているユーザで、ファイルを共有できる機能です。個人でアップロード・収集したファイル以外に、所属するグループで共有されたファイルを閲覧することができます。
ユーザのグループ所属については、3種類の権限が付与できます。(→所属ユーザの権限)
また、部署グループとは、ユーザ単位でグループ分けができる機能です。

※グループ共有機能は、別途オプションとなります。
※グループ共有機能が申し込まれていない場合は、使用できません。

グループ共有に関する設定 グループの作成、編集、削除を行います。
設定を行う場合はグループ共有機能の「グループ共有に関する設定」の[設定する]ボタンをクリックしてください。
(→グループ共有機能 : グループ共有に関する設定)
部署グループに関する設定 部署グループの作成、編集、削除を行います。
設定を行う場合はグループ共有機能の「部署グループに関する設定」の[設定する]ボタンをクリックしてください。
(→グループ共有機能 : 部署グループに関する設定)
