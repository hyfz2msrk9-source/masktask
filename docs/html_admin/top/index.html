メニュー

管理者画面のメニューです。

項目 説明
ユーザ管理 ユーザを管理します。
ログ管理 ユーザや管理者のログを、ダウンロードしたり削除したりします。
ウイルススキャンログ(※オプション) ウイルススキャンにより検出されたファイルの一覧を表示します。（※オプション機能です。お申込みがない場合は、ボタンが表示されません。）
アーカイブシステム(※オプション) ユーザが配布・受信したファイルを、保管、ダウンロードすることができます。
上長承認設定(※オプション) 上長承認機能の各ユーザ毎に上長の設定を行います。(※オプション機能です。お申し込みがない場合はボタンが表示されません。)
グループ共有機能(※オプション) グループに所属しているユーザで、ファイルを共有できる機能です。(※オプション機能です。お申し込みがない場合はボタンが表示されません。)
各種設定 各種機能の設定を行います。
運営からのお知らせ 運営からのお知らせを確認できます。
ログイン中アカウント名 現在ログインしている管理者のアカウントが表示されます。クリックすると個人設定のサブメニューが開きます。

メニューのユーザ管理、グループ共有機能(※オプション)、各種設定、ログイン中アカウント名にマウスのカーソルを合わせると、各メニューのサブメニューが表示されます。
サブメニュー内のリンクをクリックすると、直接その画面に遷移します。
