テンプレート編集

ファイル配布、収集時に使用する、メール本文のサンプルテンプレートや、メールヘッダ・フッタを編集することができます。各テンプレートの[編集]ボタンをクリックしてください。

配布用テンプレート
ファイル配布時のメール本文[サンプル文を挿入する]ボタンをクリックし、挿入される文章です。
収集用テンプレート
ファイル収集時のメール本文[サンプル文を挿入する]ボタンをクリックし、挿入される文章です。
配布・収集用テンプレート
ファイル配布・収集時のメール本文[サンプル文を挿入する]ボタンをクリックし、挿入される文章です。
ヘッダー用テンプレート
「ヘッダを付加する」設定にしている場合、Webシステムから送信するメールに付加されるヘッダです。
フッター用テンプレート
「フッタを付加する」設定にしている場合、Webシステムから送信するメールに付加されるヘッダです。

各テンプレートの内容を編集し、[確認]ボタンをクリックしてください。内容が正しければ、[変更する]ボタンをクリックし、編集を完了します。

メールヘッダ・フッタ

配布・収集・パスワード取得など、利用者から第三者に提供されるメールに挿入される固定ヘッダ・フッタを、付加したり、付加しなかったりを、設定することができます。 現在の設定が表示されています。ヘッダ・フッタそれぞれの設定をし、[更新する]ボタンをクリックしてください。設定を完了します。
