ユーザ管理

ユーザ削除

登録したユーザを削除します。
登録したユーザ一覧から、削除したいユーザの行にある[削除]ボタンをクリックしてください。
※認証方式によって、表示される設定項目が変わります。

ユーザ管理＞ユーザの削除画面へ遷移します。
削除したユーザの情報、アップロードしたファイルや引き取ったファイル、ファイル配布したときのダウンロードURLなどは削除されます。慎重に作業してください。
ユーザが他のユーザの上長に設定されており、承認待ちの依頼がある場合は、依頼は全て却下されます。

削除してもよければ、[削除する]ボタンをクリックしてください。ユーザの削除完了画面へ遷移します。

ユーザの削除が完了しました。
