ユーザ管理

CSVファイルで追加

CSVファイル(→CSVファイルの作成)を用いて、ユーザを一括追加します。
ユーザ管理画面のユーザ一覧の上にある、[CSVファイルで追加]ボタンをクリックしてください。

ユーザ管理＞CSVファイルでの追加画面に遷移します。
認証方式やオプション機能の有無によって、設定項目が変わります。
有効期限の設定が無効の場合は、ユーザ管理＞CSVファイルでの追加画面に、有効期限の項目が表示されません。
CSVユーザ追加のパスワード必須設定が無効(パスワードが未設定)の場合は、ユーザの追加が完了した後、自動的に初期パスワードを設定しユーザ情報通知を送ることができます。(→ユーザ情報の通知)
[選択…]ボタンをクリックして、CSVファイルを選択してください。選択したCSVファイルが正しければ、[インポート実行]ボタンをクリックしてください。

CSVファイルでユーザの追加が完了しました。

CSVユーザ追加のパスワード必須設定が無効の場合は、完了画面に[ユーザ情報通知へ]ボタンが表示されます。

CSVファイルの作成

ユーザを一括追加するためのCSVファイルを用意します。
認証方式やオプション機能の有無によって、設定項目が変わります。

CSVファイルは、一行目から「ユーザID,認証方式,アカウント,パスワード,初期パスワード変更,氏名（漢字）,氏名（カナ）,メールアドレス,基本容量（半角数字）,拡張容量（半角数字）,アップロード容量（半角数字：単位MB）,ファイルの定期削除の個別設定（半角数字：単位日）,機能の利用,配布機能,引取り機能,フォルダ公開機能,一斉配信機能,一斉収集機能,状態,有効期限（開始）,有効期限（終了）,メモ,管理者」のように、各項目を半角カンマ区切りで記入してください。1行につき1ユーザです。2ユーザ目からは、改行してください。

日付の形式は、yyyy-mm-dd  yyyy/mm/dd  yyyy.mm.ddのいずれかの形でご記入ください。
例）2010-07-01、2010/7/1、2010.7.1

また、Microsoft Excelを用いて、CSVファイルを作成することもできます。

Microsoft Excelでは、一行目から「ユーザID,認証方式,アカウント,パスワード,初期パスワード変更,氏名（漢字）,氏名（カナ）,メールアドレス,基本容量（半角数字）,拡張容量（半角数字）,アップロード容量（半角数字：単位MB）,ファイルの定期削除の個別設定（半角数字：単位日）,機能の利用,配布機能,引取り機能,フォルダ公開機能,一斉配信機能,一斉収集機能,状態,有効期限（開始）,有効期限（終了）,メモ,管理者」のように、各項目をセルごとに記入してください。1行につき1ユーザです。2ユーザ目からは、下の行のセルへ移動してください。

Microsoft Excelでは、ファイル形式(「フォーマット」、「ファイルの種類」と表示される場合もあります)で「CSV(カンマ区切り)（.csv）」を選択し、保存してください。
