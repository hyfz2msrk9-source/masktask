グループ共有機能を申し込まれている場合

グループ共有機能を申し込まれている場合、ユーザ追加、編集画面でユーザ追加、編集のタイミングでグループへ所属させることができます。

※グループ共有機能(→グループ共有機能)は、別途オプションとなります。

グループが1つ以上登録されていると、グループアクセス権限のフォームが表示されます。
ユーザに対して付与する、各グループごとの権限をクリックしてください。各権限の一番上にある、グループ名のないラジオボタンをクリックすると、全てのグループの権限を各権限に一括選択します。
サブフォルダも同じ内容で更新する、にチェックを入れると、共有フォルダ内に作成されたサブフォルダの権限も同じ内容になります。

管理者権限については、グループ共有機能＞編集＞グループ管理者の登録で設定することができます。
