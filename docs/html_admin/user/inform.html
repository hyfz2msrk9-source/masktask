ユーザ管理

ユーザ情報の通知

パスワード未設定のユーザにログイン情報を通知します。
※Google SSO認証、SAML認証のユーザには通知されません。

パスワード未設定のユーザがいる場合、ユーザ管理画面のユーザ一覧の上に、[ユーザ情報追加]ボタンが表示されますのでクリックしてください。

ユーザ管理>ユーザ情報の通知に遷移します。
パスワード未設定のユーザがいる場合、通知ユーザ数が表示されログイン情報の送信が可能です。

また[保存]ボタンをクリックするとテンプレートの編集内容を保存することができます。

ログイン情報を送信してもよろしければ[送信する]ボタンをクリックしてください。

ログイン情報の通知が完了しました。

パスワード未設定のユーザがいない場合、テンプレートの編集のみ可能です。
