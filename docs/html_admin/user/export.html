ユーザ管理

エクスポート

登録されている全てのユーザ情報を、CSVファイルの形式でダウンロードします。
このCSVファイルを編集し、[CSVファイルで追加]を行うと、情報が変更されている登録済みユーザに対しては更新を行うので、大量の更新作業が軽減されます。
ユーザ管理画面のユーザ一覧の上にある、[エクスポート]ボタンをクリックしてください。

[エクスポート]ボタンをクリックすると、登録されている全てのユーザ情報をCSVファイルでエクスポートします。ファイルをダウンロードしますので、お使いのパソコンに保存してください。

[注意]
エクスポートされたCSVファイルは、毎回同じファイル名がつきます。ダウンロードする時は、前回のCSVファイルとの混合にご注意ください。
