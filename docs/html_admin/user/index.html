ユーザ管理

ユーザ管理では、ユーザ一覧、ユーザ追加、CSVファイルで追加、エクスポート、ユーザ編集、ユーザ履歴、ユーザ削除、管理者一覧、管理者履歴を、操作することができます。

ユーザ管理画面は、システム側で設定された内容によって画面が異なり、「拡張容量機能を無効にしている場合の画面」と、「拡張容量機能を有効にしている場合の画面」の2通りあります。
※認証方式によって、表示される項目が変わります。
ユーザや共有グループへのストレージ割り当て状況も確認できます。

ストレージ利用状況

ユーザの登録数や容量の割り当て状況を確認できます。

共有グループ機能オンの場合※オプション

共有グループ機能を利用していない場合
