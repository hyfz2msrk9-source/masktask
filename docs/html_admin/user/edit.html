ユーザ管理

ユーザ編集

登録したユーザの情報を編集します。
登録したユーザ一覧から、編集したいユーザの行にある[編集]ボタンをクリックしてください。
※認証方式によって、表示される設定項目が変わります。

ユーザ管理＞ユーザ情報の編集画面へ遷移します。
ユーザ情報の編集画面ではアカウントロックの項目が追加されており、アカウントロックがかかったユーザの解除を行うことができます。
パスワードを変更しない場合は、空欄のままにしてください。

内容を編集し、[確認する]ボタンをクリックしてください。確認画面へ遷移します。

内容が正しければ、[変更する]ボタンをクリックしてください。完了画面へ遷移します。

ユーザの編集が完了しました。

グループ共有機能を申し込まれている場合

グループ共有機能を申し込まれている場合、ユーザ追加、編集画面でユーザ追加、編集のタイミングでグループアクセス権限を変更することで、グループへ所属させることができます。(→グループ共有機能を申し込まれている場合)
管理者権限の項目に、「権限あり」のアイコンが表示されるグループは、そのユーザにグループの管理者権限があるということを意味しています。

グループ共有機能(→グループ共有機能)は、別途オプションとなります。

グループ共有機能を申し込まれていて、オプション(ファイル上書きモード)が有効の時に、ユーザ編集画面にファイルロック機能についての文言が表示されます。
編集を行うユーザが、ファイルロックしているユーザである場合、ユーザの権限を「なし」、「読み出しのみ」に変更するとロック解除が行われます。
ファイルロック機能はグループ設定で有効／無効の設定が可能です。(→グループ設定)
