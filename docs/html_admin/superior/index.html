上長承認設定(※オプション)

上長承認機能はオプション機能です。別途、お申込みが必要となります。
上長承認機能が有効でない場合は、メニューに「上長承認設定」が表示されません。

上長承認機能が有効な場合は、ユーザがファイルの配布(メーラーからの配布)、フォルダ公開(メーラーからのフォルダ公開)、配布と引取同時送信機能を利用した場合に、設定された上長の承認が必要となります。上長承認設定画面では、ユーザの上長を設定することができます。

また、上長承認の際に、メール詳細画面にて配布ファイルがダウンロードされたかをチェックする機能もございます。(→上長承認に関する設定)

CSVファイルで設定

CSVファイルで追加では、CSVファイル(→CSVファイルの作成)を用いて、ユーザの上長を一括設定します。

上長承認設定画面から[CSVファイルで設定]ボタンをクリックします。

上長承認設定＞CSVファイルでの設定画面に遷移します。
[選択…]ボタンをクリックして、CSVファイルを選択してください。選択したCSVファイルが正しければ、[インポート実行]ボタンをクリックしてください。

CSVファイルがインポートされ、ユーザの上長が設定されました。

CSVファイルの作成

ユーザの上長を設定するためのCSVファイルを用意します。

CSVファイルは、 一行目から「設定するユーザのアカウント,上長のアカウント1,上長のアカウント2,上長のアカウント3,上長のアカウント4,上長のアカウント5」のように、各項目を半角カンマ区切りでご記入ください。
1行につき1ユーザの設定です。2ユーザ目からは、改行してください。
(※最大上長設定可能数は、お申し込み内容によって異なります)

また、Microsoft Excelを用いて、CSVファイルを作成することもできます。
Microsoft Excelでは、 セルごとにアカウントを記入してください。

Microsoft Excelでは、保存時にファイルの種類を「CSV(カンマ区切り)（*.csv）」を選択し、保存してください。
