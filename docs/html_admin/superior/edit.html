上長承認設定(※オプション)

各ユーザ毎の上長設定

各ユーザ毎に上長を設定する場合は、上長承認設定画面のユーザ一覧、[編集]ボタンをクリックします。

[編集]ボタンをクリックすると、各ユーザ毎の上長設定画面へ遷移します。

上長が設定されていないユーザーに対して、ログインを許可するかどうかを選択できます。

ユーザ一覧から、設定する上長をクリックすると、上長を選択することができます。(複数選択可能)
選択されると、背景が青に変わります。

上長を選択した後、[選択ユーザをすべて追加]ボタンをクリックすると、上長一覧に選択した上長が追加されます。

上長一覧では、上長の優先順位をドラッグ＆ドロップで変更することができます。ユーザが上長を選択する場合に、表示される上長の順番です。

承認方式は次の二通りから選べます。

「いずれかの上長からの承認を必要とする」の場合
ユーザはメールの作成時に一名以上の上長を選択します。
ユーザが指定した上長のうち一名が承認すればメールが送信されます。

「すべての上長からの承認を必須にする」の場合
設定されたすべての上長が承認するまでメールは送信されません。

上長の追加、優先順位の変更後、[変更する]ボタンをクリックすると、上長の設定が完了します。
