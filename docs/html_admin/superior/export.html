上長承認設定(※オプション)

CSVエクスポート

設定されている全てのユーザの上長設定を、CSVファイルの形式でダウンロードします。このCSVファイルを編集し、[CSVファイルで設定]を行うと、情報が変更されているユーザに対して更新を行います。
CSVエクスポートを行うには、上長承認設定画面から [CSVエクスポート]ボタンをクリックします。

[エクスポート]ボタンをクリックすると、登録されている全てのユーザの上長設定をCSVファイルでエクスポートします。ファイルをダウンロードしますので、お使いのパソコンに保存してください。

[注意]
エクスポートされたCSVファイルは、毎回同じファイル名がつきます。ダウンロードする時は、前回のCSVファイルとの混合にご注意ください。
