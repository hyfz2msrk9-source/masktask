個人設定

右上に表示されているログイン中アカウント名をクリックすると、以下の機能を利用できます。

パスワード変更

ログインしている管理者のパスワードを変更します。
パスワードは定期的に変更されることをお勧めします。現在のパスワード、新しいパスワード、確認のため新しいパスワード(再入力)を入力し、[変更する]ボタンをクリックしてください。正しく認証されましたら、パスワードを変更します。

パスワード変更後は、パスワード変更完了画面へ遷移し、自動的にログアウトされます。
[ログイン画面へ移動]ボタンをクリックすると、ログイン画面へ遷移しますので、もう一度ログインしてください。

二要素認証の設定

管理者画面で二要素認証が有効な場合に表示されます。
ログイン中のアカウントの二要素認証を設定できます。
設定が有効な場合、二要素認証が使えなくなった時に備えてバックアップコードを作成することもできます。
