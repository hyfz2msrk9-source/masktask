ログ管理

ログ管理では、ユーザや管理者の操作ログをCSV形式でダウンロードできるほか、指定日付以前のログの削除を行います。メニュー：ログ管理をクリックしてください。

ログダウンロード

ログには2種類あります。通常のログ(→直近24時間のログをダウンロード) と、定期的にファイル保管されるログ(→定期保管のログをダウンロード)です。

※共有グループの履歴のダウンロードはグループ共有オプションをお申込みの場合のみご利用頂けます。

直近24時間のログをダウンロード

直近24時間のユーザと管理者の操作ログを、CSVファイルでダウンロードします。
対象を、全て(管理者＋ユーザ)・管理者・ユーザ・グループから選択し、[ダウンロード]ボタンをクリックしてください。

定期保管のログをダウンロード

月ごとに定期的にファイル保管されるログを、ダウンロード及び削除が可能です。 ファイル保管されているログがあると、下記図 のように、年月とダウンロードリンク、[削除]ボタンが表示されます。
ダウンロードする場合は、ダウンロードしたい対象の年月の管理者またはユーザ、グループのダウンロードリンクをクリックしてください。
削除は、ログが保管されているファイルを削除します。その年月の管理者とユーザとグループのログを一度に削除します。削除する場合は、年月の[削除]ボタンをクリックしてください。
ファイル保管されているログを削除しても、指定年月のログ(→直近24時間のログをダウンロード)は残ります。指定年月のログを削除する場合は、ログ削除(→ログ削除)を行ってください。

ログ削除

指定した日付より、以前のログを削除します。
日付を選択し、[削除]ボタンをクリックしてください。

指定した日付より以前のログがある場合、ログ削除の確認画面を表示します。[削除する]ボタンをクリックすると、ログを削除します。
