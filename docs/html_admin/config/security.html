二要素認証に関する設定
※この設定は、Google SSO認証、SAML認証のユーザには適用されません。
二要素認証機能 管理者側・ユーザ側それぞれについて、二要素認証機能の有効/無効の設定や、二要素認証の認証方法の選択が行えます。
有効にすると各ユーザは二要素認証機能をメール、または認証アプリで利用できます。
二要素認証機能を有効から無効にした時、 ユーザごとの二要素認証機能の設定も「使用しない」に切り替わります。
認証アプリで二要素認証をする方法から変更した場合、ユーザが設定した認証アプリとの連携は解除されます。
認証アプリで二要素認証をする場合、管理者側ではユーザごとの設定は「使用する」に変更できません。
二要素認証の確認頻度 何日ごとに二要素認証の確認を行うかの設定をします。
前回の二要素認証から、指定された日数経過後のログイン時に、二要素認証を行います。
認証方法を変更すると、経過した日数のカウントがリセットされます。
0日を設定されますと、ログイン時に毎回二要素認証を行います。
管理者側で二要素認証を有効化した場合、ログイン中のアカウントの二要素認証は個人設定から設定できます。(→二要素認証)
連続ログインに関する設定
ユーザ側画面へのログイン、管理側画面へのログインともに共通の設定になります。
メール通知設定 連続ログイン通知機能の有効/無効の設定が行えます。
設定が有効の場合、ログイン試行の履歴をカウントします。連続ログイン計測時間の間に連続ログイン回数の設定値以上ログインが試行された時に、通知先へメールを送信します。
連続ログイン計測時間 連続ログインをカウントする時間を設定します。
※メール通知設定が有効の場合は、1〜10を設定してください。
通知を行う連続ログイン回数 通知を行う連続ログイン回数を設定します。
※メール通知設定が有効の場合は、1〜100を設定してください。
通知先メールアドレス メールの送信先を設定します。
※メール通知設定が有効の場合は、通知先を一つ以上設定してください。
通知方法 通知方法を設定します。
「毎回通知する」に設定すると、ログイン試行回数が設定値以上になるたびにメールを送信します。
「初回のみ通知する」に設定すると、ログイン試行回数が設定値以上になった最初の時点のみメールを送信します。

クライアント認証に関する設定(※オプション)
クライアント認証機能はオプション機能です。別途、お申込みが必要となります。
クライアント認証機能が有効でない場合「クライアント認証に関する設定」は表示されません。
管理者画面アクセス制限 管理者側画面のアクセス制限を、クライアント証明書によって行います。
ユーザ画面アクセス制限 ユーザ側画面のアクセス制限を、クライアント証明書によって行います。
の認証設定 機能のオプションをご利用で、クライアント認証機能でアクセス制限を行った場合に、 の認証を許可するかの設定を行います。
各管理者・ユーザ画面アクセス制限で、「クライアント認証によるアクセス制限を利用する」と設定すると、「アクセス制限による設定」アクセス許可されたIPは、クライアント認証を行わない」設定がチェック出来るようになります。

設定をチェックすると、アクセス制限に関する設定(→ アクセス制限)でアクセス許可されたIPアドレスである場合、クライアント認証を行わずにアクセス可能となります。
もしアクセス許可されていないIPアドレスである場合は、クライアント認証によるアクセス制限を行います。
クライアント認証に関する設定とアクセス制限に関する設定を組み合わせることで、ユーザ画面や管理画面へのパスワード認証のセキュリティをより強化することが可能です。用途に合わせて設定を行ってください。

クライアント証明書認証かつ登録IPアドレスのみログインを許可する場合

クライアント証明書を所有しているPCと登録IPアドレスからのアクセスのみログインを許可する設定です。
アクセス制限に関する設定で「登録IPアドレスのみアクセス可能」に設定を行ってください。 また、アクセスを許可するIPアドレスを登録してください。 (→ アクセス制限)

クライアント認証に関する設定で「クライアント認証によるアクセス制限を利用する」に設定してください。 また、『「アクセス制限に関する設定」でアクセス許可されたIPは、クライアント認証を行わない』のチェックを外してください。

クライアント証明書認証もしくは登録IPアドレスのみログインを許可する場合

クライアント証明書を所有しているPCまたは、所有していないPCの場合は登録しているIPアドレスからのアクセスのみログインを許可する設定です。
アクセス制限に関する設定で「登録IPアドレスのみアクセス可能」に設定を行ってください。 また、アクセスを許可するIPアドレスを登録してください。 (→ アクセス制限)
クライアント認証に関する設定で「クライアント認証によるアクセス制限を利用する」に設定してください。 また、『「アクセス制限に関する設定」でアクセス許可されたIPは、クライアント認証を行わない』にチェックを入れてください。

クライアント証明書認証のみログインを許可する場合

クライアント証明書を所有しているPCのみログインを許可する設定です。
アクセス制限に関する設定で「全てのIPよりアクセス可能」に設定を行ってください。 (→ アクセス制限)
クライアント認証に関する設定で「クライアント認証によるアクセス制限を利用する」に設定してください。 また、『「アクセス制限に関する設定」でアクセス許可されたIPは、クライアント認証を行わない』のチェックを外してください。

の認証設定について

「ユーザ画面アクセス制限」の設定を「クライアント認証によるアクセス制限を利用する」に設定し、 からのアクセスを許可する場合は、「 の認証を許可する」に 設定に設定してください。 また、 からのアクセスを拒否（利用不可）する場合は、「 の認証を拒否する」に 設定に設定してください。 からログインができなくなります。

ファイル形式に関する設定
システム全体で制限する形式のホワイトリスト・ブラックリストを設定します。
[.]から始まる英数字でファイルの拡張子を登録してください。全ての拡張子を登録する場合は、[*]を登録してください。
ファイル形式の
利用設定		 ファイル形式の利用設定では、利用方法をホワイトリストかブラックリストのどちらかを設定します。

利用を許可するファイル形式を設定する場合は、「ホワイトリストを利用する」を選択してください。設定されたファイル形式のみ利用可能となります。
利用を許可しないファイル形式を設定する場合は、「ブラックリストを利用する」を選択してください。設定されたファイル形式の利用が不可能となります。
ホワイトリスト
の設定		 ファイル形式を追加する場合は、[ファイル形式入力]欄にファイル形式を入力し、[+追加]ボタンを押します。
※ファイル形式は[.]から始まる英数字の拡張子を入力してください。全ての拡張子を登録する場合は[*]を入力してください。

ファイル形式を削除する場合は、[ファイル形式一覧]から削除するファイル形式を選択し、[×削除]ボタンを押します。
ブラックリスト
の設定		 ファイル形式を追加する場合は、[ファイル形式入力]欄にファイル形式を入力し、[+追加]ボタンを押します。
※ファイル形式は[.]から始まる英数字の拡張子を入力してください。全ての拡張子を登録する場合は[*]を入力してください。

ファイル形式を削除する場合は、[ファイル形式一覧]から削除するファイル形式を選択し、[×削除]ボタンを押します。

上長承認機能はオプション機能です。別途、お申込みが必要となります。
上長承認機能が有効でない場合「上長承認に関する設定」は表示されません。
上長承認でのファイルチェック方法 上長承認の際に、上長によって全てのファイルがダウンロードまたはプレビューされたかチェックを行う機能です。
※この機能はフォルダ公開には適用されません。
ファイルの無害化に関する設定(※オプション)
ファイルの無害化はオプション機能です。別途、お申込みが必要となります。
この環境では無害化前ファイルは保持されません。
ファイルの無害化機能が有効でない場合「ファイルの無害化に関する設定」は表示されません。
無害化前のファイル ファイルアップロード時、無害化前のファイルを残すかの設定です。
ファイルを残す場合、無害化前・後それぞれのファイルの容量がアップロード容量としてカウントされます。
