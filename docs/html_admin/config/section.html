各種設定

グループ共有機能 : 部署グループに関する設定(※オプション)

グループ共有機能は、グループに所属しているユーザで、ファイルを共有できる機能です。個人でアップロード・収集したファイル以外に、所属するグループで共有されたファイルを閲覧することができます。
ユーザのグループ所属については、3種類の権限が付与できます。(→所属ユーザの権限) 部署グループとは、ユーザ単位でグループ分けができる機能です。

※グループ共有機能は、別途オプションとなります。
※グループ共有機能が申し込まれていない場合は、使用できません。

部署グループ設定

部署グループの作成、編集、削除をする場合は、グループ共有機能の「部署グループに関する設定」の[設定]ボタンをクリックしてください。
部署グループの一覧画面に遷移します。

部署グループ追加

部署グループを作成します。[部署グループ追加]をクリックしてください。

部署グループ追加の画面に遷移します。
部署グループ名を入力し、所属させたいユーザを「部署グループ無所属ユーザ」からクリックして選択します。
矢印の[選択ユーザをすべて追加]をクリックすると、「部署グループ所属ユーザ」に登録されます。矢印の[選択ユーザをすべて削除]ボタンをクリックすると、選択されたユーザが削除されます。
部署グループ所属ユーザを設定し、[追加]ボタンをクリックすると新しく部署グループが追加されます。

部署グループ名作成したい部署グループ名を入力します。
部署グループ無所属ユーザ部署に所属していないユーザの一覧です。
[選択ユーザをすべて追加]ボタン「部署グループ無所属ユーザ」一覧から、選択したユーザを部署に追加します。
部署グループ所属ユーザ部署に所属しているユーザの一覧です。
[選択ユーザをすべて削除]ボタン「部署グループ所属ユーザ」一覧から選択したユーザを部署から削除します。
追加ボタン部署グループのユーザを設定完了します。

部署グループ編集

部署グループを編集します。
編集したい部署の部署名をクリックすると、部署グループ編集/削除の画面に遷移します。
部署グループ名を変更したい場合は、部署グループ名を変更します。
ここで所属ユーザの 追加も可能です。(→部署グループ追加) 編集が完了すると、[編集]ボタンをクリックします。

部署グループ削除

部署グループを削除します。
任意の部署を選択し、[削除]ボタンをクリックすると、部署が削除されます。

メンバー追加(CSV)

部署グループのメンバーをCSV形式ファイルで追加します。
部署グループ一覧の任意の部署グループをクリックし、[メンバー追加(CSV)]ボタンをクリックしてください。

部署グループのメンバーをCSV形式ファイルで追加します。
部署グループ一覧の任意の部署グループをクリックし、[メンバー追加(CSV)]ボタンをクリックしてください。

CSVファイルは、1行目から「アカウント」、「所属の有無」の順でカンマ区切りで作成してください。 所属の有無は、「1(所属する)」、「0(所属しない)」で必ず入力してください。

CSVエクスポート

部署グループループのメンバー一覧をCSVファイル形式でエクスポートします。
CSVファイルでインポートを行う場合に利用することができます。
部署グループ一覧の任意のグループの[CSVエクスポート]ボタンをクリックしてください。
