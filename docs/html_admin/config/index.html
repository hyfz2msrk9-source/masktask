各種設定

グループ共有機能や、各種機能の設定を行います。メニュー：各種設定をクリックすると、各種設定画面へ遷移します。
各種設定画面は、システム管理者のみアクセスできます。
設定項目は、契約内容によって異なります。

各種設定画面は、操作設定、セキュリティ設定、その他設定、システム設定の4つに分類されています。
各設定をクリックすると、分類されている設定の一覧画面へ遷移します。
各設定に表示されているリンクをクリックすると、直接その設定画面へ遷移します。

操作設定 ユーザ側画面の、配布、引取り(収集)、アップロード、ファルダ公開の操作に関する設定です。(→操作設定)

・配布に関する設定
・引取り(収集)に関する設定
・アップロードに関する設定
・ファルダ公開に関する設定
・送信者（差出人）に関する設定
・一斉配信に関する設定
・一斉収集に関する設定
