操作設定

メニュー：各種設定の中の操作設定をクリックしてください。操作設定画面へ遷移します。

配布に関する設定
配布機能 ユーザ操作側の配布機能の無効・有効設定です。
有効に設定すると、ユーザはファイルの配布が行えます。
無効に設定すると、ユーザはファイルを配布することができません。
ユーザ管理 → ユーザの登録またはユーザ情報の編集 → 配布機能 にてユーザごとの設定も可能です。(→ユーザ追加)
最大送信人数 メールを一度に送信する人数の上限の設定が行えます。設定する人数は、引取り(収集)の最大人数と共通しています。(→引取り(収集)に関する設定)
最大送信ファイル数 ファイル配布時、一度に送信できるファイル数の上限の設定が行えます。
メーラーからの
送信機能		 ファイル配布のメーラーから送信機能の有効・無効設定です。
有効にすると、ファイル配布時に[自分のメーラーから送信する]ボタンが表示され、メーラーから送信することができます。
メーラからの送信機能を有効にすると、配布時のデフォルト機能にする・しないを設定することができます。
引取り(収集)
同時送信機能		 ファイル配布とファイルの収集URLを同時に送信する機能の有効・無効設定です。
有効にするとファイル配布時に「引取りと配布メールを送信する」ボタンが表示され、ファイル配布とファイルの収集を同時に送信することができます。
メーラーからの
引取り（収集）
同時送信機能		 メーラーからファイル配布とファイルの収集URLを同時に送信する機能の有効・無効設定です。
有効にするとファイル配布時に「メーラーから引取りと配布を送信する」ボタンが表示され、ファイル配布とファイルの収集を同時に送信することができます。
引取り(収集)同時メール
送信待機時間設定		 引取り(収集)同時メール送信待機機能を設定します。
「利用する」もしくは「ユーザ任意」を選択すると設定画面が表示されます。指定時間を設定すると、設定した時間が経過するまでメールは送信されません。
ユーザ任意設定の場合、ユーザが設定可能な最低値として設定されます。
サンプル文初期入力機能 設定してあるサンプル文の初期表示機能の設定です。
有効にするとファイル配布時にメールの本文にサンプル文が初期表示されます。
フォルダ公開機能には適用されません。ご注意ください。
パスワードロック機能 ファイル配布時のパスワードロックの設定です。フォルダ公開機能には、適応されません。
ZIPパスワード機能 ファイル配布時のZIPパスワードの設定です。
zipファイルに圧縮し、パスワードを自由に指定する機能の有効・無効を設定します。フォルダ公開機能には、適応されません。
ファイルの自動削除機能 ファイルの自動削除をデフォルトで行うかどうかの設定です。
フォルダ公開機能には、適応されません。
配布メール
送信待機時間設定		 配布メール送信待機機能を設定します。
「利用する」もしくは「ユーザ任意」を選択すると設定画面が表示されます。指定時間を設定すると、設定した時間が経過するまでメールは送信されません。
ユーザ任意設定の場合、ユーザが設定可能な最低値として設定されます。

一斉配信に関する設定
一斉配信機能 ユーザ操作側の一斉配信機能について、有効・無効を設定します。
有効に設定すると、ユーザは一斉配信を使用できます。
無効に設定すると、ユーザは一斉配信を使用できません。
ユーザ管理 → ユーザの登録またはユーザ情報の編集 → 一斉配信機能 にてユーザごとの設定も可能です。(→ユーザ追加)
配信の種類 許可する配信の種類を設定します。
最大送信人数 1件の配信で送信できる宛先件数の上限値を設定します。
最大送信ファイル数 ファイルあり配信における、1件の宛先に送信できるファイル数の上限値を設定します。
送信予定日時の上限 設定可能な一斉配信メールの送信予定日時の上限日数です。
上長承認が必要な場合は、送信予定日時の上限が承認期限にもなります。
サンプル文初期入力機能 ファイルあり配信における、サンプル文の初期入力機能を設定します。
有効にすると、配布メール作成時にメール本文にサンプル文が入力された状態で表示されます。
パスワードロック機能 ファイルあり配信における、パスワードロック機能を設定します。
ZIPパスワード機能 ファイルあり配信における、ZIPパスワードを設定します。
配布するファイルを1つのZIPファイルに圧縮し、パスワードを指定する機能の有効・無効を設定できます。

指定パスワードまたはZIPパスワードを選択した際に、配信と同時にパスワードをメール通知する機能の有効・無効を設定できます。
ダウンロード有効期限 配布メールにおける、ダウンロード有効期限のプルダウンメニューを設定します。
有効期限リストをドラッグ＆ドロップすることで、表示順序の入れ替えができます。
