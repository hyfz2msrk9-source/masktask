各種設定

ドメイン送信制限

ドメイン送信制限とは、配布メールや引取り(収集)依頼メールの宛先に指定するメールアドレスのドメインを、フィルタリングできる機能です。
個人別のホワイトリスト・ブラックリスト、全ユーザ共通のホワイトリスト・ブラックリストの4種類を設定できます。

フィルタリングの順序について

配布や引取りメールの送信時は、下記の順番でリストを参照してフィルタリングを行います。
個人と共通のリストに重複してドメインが登録されていた場合は、個人リストの設定が優先されます。

個人のホワイトリストに合致  →  ○送信可
リストに合致しない場合
個人のブラックリストに合致  →  ×送信不可
リストに合致しない場合
共通のホワイトリストに合致  →  ○送信可
リストに合致しない場合
共通のブラックリストに合致  →  ×送信不可
リストに合致しない場合
全てのリストに合致しない  →  ○送信可

CSVファイルで設定

CSVファイルで追加する場合は、CSVファイル(→CSVファイルの作成)を用いて、ドメインを一括登録します。

ドメイン送信制限に関する設定画面から[CSVファイルで設定]ボタンをクリックします。

ドメイン送信制限に関する設定>CSVインポート画面に移動します。
[選択･･･]ボタンをクリックして、CSVファイルを選択してください。選択したCSVファイルが正しければ、[インポート実行]ボタンをクリックしてください。

CSVファイルがインポートされ、ドメインの設定が登録されました。

CSVファイルの作成

ホワイトリスト、ブラックリストへドメインを登録するためのCSVファイルを用意します。

CSVファイルは、 一行目から「アカウント,リスト種別,ドメイン」のように、各項目を半角カンマ区切りでご記入ください。
※アカウントは、「個人設定」を行う場合は設定するユーザのアカウント、「共通設定」を行う場合は"共通"と記載してください。
※リスト種別は、「ホワイトリスト」に登録する場合は"ホワイトリスト"または"0"、「ブラックリスト」に登録する場合は"ブラックリスト"または"1"と記載してください。
1行につき、1つの設定を記入してください。次の設定は改行して記入してください。
※ドメインの入力フォーマットは、ドメインの入力フォーマットを参照してください。


また、Microsoft Excelを用いて、CSVファイルを作成することもできます。
Microsoft Excelでは、 一行目からセルごとに「アカウント,リスト種別,ドメイン」のように、各項目を半角カンマ区切りでご記入ください。
※アカウントは、「個人設定」を行う場合は設定するユーザのアカウント、「共通設定」を行う場合は"共通"と記載してください。
※リスト種別は、「ホワイトリスト」に登録する場合は"ホワイトリスト"または"0"、「ブラックリスト」に登録する場合は"ブラックリスト"または"1"と記載してください。
1行につき、1つの設定を記入してください。次の設定は改行して記入してください。
※ドメインの入力フォーマットは、ドメインの入力フォーマットを参照してください。

Microsoft Excelでは、保存時にファイルの種類を「CSV(カンマ区切り)（*.csv）」を選択し、保存してください。

エクスポート

ドメイン制限設定の一覧をCSVファイル形式でエクスポートします。
ドメイン送信制限に関する設定画面から[CSVエクスポート]ボタンをクリックしてください。

個人設定

ドメイン送信制限に関する設定画面から[個人設定]ボタンをクリックします。


ユーザ検索欄に「アカウント」「メールアドレス」「ユーザ氏名」「メモ」を入力し、ドメイン制限設定を行いたいユーザを検索します。
検索結果の一覧からユーザを選択し、[編集]ボタンをクリックしてください。



ホワイトリストの設定 個人のホワイトリストです。
ドメインを追加する場合は、[ドメイン入力]欄にドメインを入力し、[+追加]ボタンを押します。
※ドメインの入力フォーマットは、ドメインの入力フォーマットを参照してください。

ドメインを削除する場合は、[ドメイン一覧]から削除するドメインを選択し、[×削除]ボタンを押します。
ブラックリストの設定 個人のブラックリストです。
ドメインを追加する場合は、[ドメイン入力]欄にドメインを入力し、[+追加]ボタンを押します。
※ドメインの入力フォーマットは、ドメインの入力フォーマットを参照してください。ドメインを削除する場合は、[ドメイン一覧]から削除するドメインを選択し、[×削除]ボタンを押します。

共通設定

ドメイン送信制限に関する設定画面から[共有設定]ボタンをクリックします。



ホワイトリストの設定 全ユーザ共通のホワイトリストです。
ドメインを追加する場合は、[ドメイン入力]欄にドメインを入力し、[+追加]ボタンを押します。
※ドメインの入力フォーマットは、ドメインの入力フォーマットを参照してください。

ドメインを削除する場合は、[ドメイン一覧]から削除するドメインを選択し、[×削除]ボタンを押します。
ブラックリストの設定 全ユーザ共通のブラックリストです。
ドメインを追加する場合は、[ドメイン入力]欄にドメインを入力し、[+追加]ボタンを押します。
※ドメインの入力フォーマットは、ドメインの入力フォーマットを参照してください。
ドメインを削除する場合は、[ドメイン一覧]から削除するドメインを選択し、[×削除]ボタンを押します。

ドメインの入力フォーマット

個人別のホワイトリスト・ブラックリスト、全ユーザ共通のホワイトリスト・ブラックリストに設定するドメインの入力フォーマットは下記の通りです。
入力ドメイン 対象メールアドレス
abc@example.jp メールアドレスが abc@example.jp のときに対象となります。
example.jp メールアドレスのドメイン（"@"マークの右側）が example.jp のときに対象となります。
*.example.jp メールアドレスのドメイン（"@"マークの右側）が example.jp のとき、および、 *.example.jp のときに対象となります。
*.jp メールアドレスのドメイン（"@"マークの右側）が *.jp のときに対象となります。
「jp」のトップドメイン部分は、4文字まで登録可能です。
* 全てのメールアドレスが対象となります。
