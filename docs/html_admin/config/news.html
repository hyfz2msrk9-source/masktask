各種設定

運営からのお知らせ

運営からのお知らせを表示するかどうかの設定です。 (→運営からのお知らせ)

お知らせ機能

お知らせ機能は、ユーザ全員のログイン時、お知らせを表示させる機能です。
タイトルをクリックすると、ユーザは詳細を見ることができます。

お知らせの追加

お知らせを作成します。[お知らせ追加]ボタンをクリックしてください。お知らせ追加画面へ遷移します。

各項目を入力し、[追加する]ボタンをクリックしてください。
英語、中国語の項目を未入力とした場合、英語、中国語画面にも、日本語の「タイトル」と「本文」が表示されます。

お知らせの編集・削除

お知らせを編集、削除します。

[編集]ボタンをクリックすると、編集画面に遷移しますので、任意の項目を編集し、[更新する]ボタンをクリックしてください。

[削除]ボタンをクリックすると、確認画面に遷移します。
[削除する]ボタンをクリックすると、削除されます。削除したお知らせは、ユーザのログイン画面でも表示されなくなりますので、ご注意ください。
