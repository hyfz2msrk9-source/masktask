各種設定

テンプレート編集

ファイル配布、収集時に使用する、メール本文のサンプルテンプレートや、メールヘッダ・フッタを編集することができます。

テンプレート編集

テンプレートの編集を行う場合は、各テンプレートの[編集]ボタンをクリックしてください。
各テンプレートには、日本語版と英語版の2種類あります。

配布用テンプレート
ファイル配布時のメール本文[サンプル文を挿入する]ボタンをクリックし、挿入される文章です。
収集用テンプレート
ファイル収集時のメール本文[サンプル文を挿入する]ボタンをクリックし、挿入される文章です。
配布・収集用テンプレート
ファイル配布・収集時のメール本文[サンプル文を挿入する]ボタンをクリックし、挿入される文章です。
配布ワンタイムパスワード用テンプレート
ファイル配布時にワンタイムパスワードを設定している場合、ワンタイムパスワードが届く時のメール本文です。
収集ワンタイムパスワード用テンプレート
ファイル収集時にワンタイムパスワードを設定している場合、ワンタイムパスワードが届く時のメール本文です。
ヘッダー用テンプレート
メールヘッダ・フッタの設定で「ヘッダを付加する」設定にしている場合、Webシステムから送信するメールに付加されるヘッダです。
フッター用テンプレート
メールヘッダ・フッタの設定で「フッタを付加する」設定にしている場合、Webシステムから送信するメールに付加されるヘッダです。

メールヘッダ・フッタ・配信停止リンク

配布・収集・パスワード取得などの利用者から第三者に送信するメールへ、固定ヘッダ・フッタ・配信停止リンクを挿入するか設定することができます。
配信停止リンクの挿入は、 一斉配信・一斉収集のメールのみが対象です。
ページへの遷移直後は現在の設定が表示されています。
変更したい場合は選択状況を変更し、[更新する]ボタンをクリックしてください。
