システム設定

メニュー：各種設定の中のシステム設定をクリックしてください。
システム設定画面へ遷移します。
システム設定画面は、管理者管理で新しく追加された管理者は設定することが出来ません。設定内容の確認のみとなります。

システム設定の確認のみ可能な場合

システム設定可能な場合

ユーザ側に関する設定
マニュアルとヘルプ表示可否 ユーザ側画面で操作マニュアルを表示する可否を設定します。
グループ管理者による
ユーザ作成時の容量		 グループ管理者に設定されているユーザが、ユーザ側画面で新しくユーザを作成する際に設定できる容量を設定します。
未ログインアカウント削除日数 ログインしていないアカウントを削除する日数を設定します。
0を設定するとアカウント削除は行われません。
管理側に関する設定
マニュアルとヘルプ表示可否 管理側画面で操作マニュアルを表示する可否を設定します。
送信待機機能の利用可否 送信待機機能の利用可否を設定します。
「利用する」を選択すると、配布に関する設定と引取り(収集)に関する設定に、送信待機機能が追加されます。
ロゴに関する設定
英語版 英語版で使用するロゴを登録します。画面上の「全て英語版を利用する」にチェックすると、日本語版も英語版と同じロゴが使用されます。
日本語版 日本語版で使用するロゴを登録します。
中国語版  簡体字 中国語版(簡体字)で使用するロゴを登録します。中国語版の設定が有効の場合のみ設定可能です。
中国語版  簡体字 中国語版(繁体字)で使用するロゴを登録します。中国語版の設定が有効の場合のみ設定可能です。
