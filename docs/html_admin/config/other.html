ユーザ画面に関する設定
ファイル一覧画面(ファイル一覧画面で利用される機能の設定)
ファイル移動機能 ユーザのフォルダ間の移動を有効・無効の設定が行えます。有効に設定すると、ユーザはフォルダ間でファイルの移動ができます。無効に設定すると、ユーザはファイルの移動が行えません。
一括ダウンロード機能 ファイル一覧の各フォルダに保存されているファイルを、一括でダウンロードする機能の有効・無効を設定できます。
有効にすると、フォルダ毎に一括ダウンロードが可能になります。無効にすると、一括ダウンロードは行えません。

[一括ダウンロード機能が使える画面]
・ユーザのファイル一覧
・フォルダ公開時、送信先のダウンロード用ファイル一覧
(→フォルダ公開)

[注意]
一括ダウンロード機能は一部の環境のみでご利用可能です。
共有フォルダ検索機能 共有フォルダ検索の有効・無効を設定する機能です。有効に設定すると、ユーザが共有フォルダの検索を行うことができます。無効に設定すると、共有フォルダの検索は行えません。

[注意]
共有フォルダ機能はオプション機能です。機能を有効にするには、別途お申し込みが必要です。共有フォルダ検索機能は、共有フォルダ内のファイルを検索する機能ではありません。
メーターの表示 個人フォルダ、共有フォルダのメーターの表示の有効・無効を設定する機能です。
フォルダツリー 有効にすると、フォルダツリーにスクロールバーを表示します。
フォルダのフルパス 有効にすると、フォルダのフルパスを表示します。
ファイル一覧の項目 ・フォルダの表示
有効にすると、ファイル一覧内にもフォルダを表示します。また、ファイル検索機能でのフォルダ名検索も有効になります。
・登録者
有効にすると、共有フォルダ内のファイルについて、登録者を表示します。

[注意]
共有フォルダ機能はオプション機能です。機能を有効にするには、別途お申し込みが必要です。
アドレス帳画面(アドレス帳画面で利用される機能の設定)
共通アドレス帳表示 ユーザのアドレス帳画面にて、共有アドレスを表示するかどうかの設定を行うことができます。
履歴画面(履歴画面で利用される機能の設定)
IPアドレス表示 ユーザの履歴画面にて、IPアドレスを表示するかどうかの設定を行うことができます。
サポート画面(サポート画面で利用される機能の設定)
システム管理者への連絡方法 ユーザのサポート画面からシステム管理者へ連絡する際の、連絡方法の設定を行うことができます。
電話を選択した場合、「システム管理者の連絡先」に設定した電話番号がサポート画面に表示されます。
メールを選択した場合、「システム管理者の連絡先」に設定したメールアドレスにメールが送信されます。
システム管理者の連絡先 ユーザのサポート画面からシステム管理者へ連絡する際の、連絡先の設定を行うことができます。
お知らせに関する設定(→お知らせ機能)
お知らせ機能 運営からのお知らせの表示設定や、ユーザ画面に表示するお知らせの作成、編集、削除を行います。
アーカイブに関する設定(※オプション)
アーカイブ機能はオプション機能です。別途、お申込みが必要となります。
アーカイブ機能が有効でない場合「アーカイブに関する設定」は表示されません。
アーカイブ機能設定 アーカイブを行うときのファイル操作を選択します。
アップロード時、配布時・フォルダ公開時、収集時の中からアーカイブを行うときの操作にチェックをつけてください。
アーカイブ
警告メールを送信する
容量設定		 警告メールを送信するための設定です。設定する容量の割合を超えると警告メールが送信されます。
0を設定するとメールは送られません。また、管理者管理で新しく追加された管理者は設定する事が出来ません。
アーカイブ
データを削除する
容量設定		 データを削除する設定です。設定する容量の割合を超えると自動的にデータが削除されます。
0を設定すると削除は行われません。また、管理者管理で新しく追加された管理者は設定する事が出来ません。
Eviエクスポート
警告メールを送信する
容量設定		 警告メールを送信するための設定です。設定する容量の割合を超えると警告メールが送信されます。
0を設定するとメールは送られません。また、管理者管理で新しく追加された管理者は設定する事が出来ません。
Eviエクスポート
データを削除する
容量設定		 データを削除する設定です。設定する容量の割合を超えると自動的にデータが削除されます。
0を設定すると削除は行われません。また、管理者管理で新しく追加された管理者は設定する事が出来ません。
保管期間設定 アーカイブファイルを保管する期間を設定します。作成日から指定された期間を過ぎたアーカイブファイルは、自動的に削除されます。0日を指定した場合は、無期限に保管されます。
定期エクスポート 定期エクスポートを行うタイミングを指定します。

[注意]
月単位で定期エクスポートを行う場合は、アーカイブファイルの保管期間を31日以上に指定してください。
週単位で定期エクスポートを行う場合は、保管期間を7日以上に指定してください。
保管期間を短く設定していた場合、エクスポートが行われる前にファイルが削除されます。
エクスポートファイル
保管期間設定		 エクスポートされたファイルの保管期間を設定します。作成日から指定された期間を過ぎたエクスポートファイルは、自動的に削除されます。0日を指定した場合は、無期限に保管されます。
メールアドレス エクスポート完了通知や、容量超過の警告メールを通知するメールアドレスを設定します。","（カンマ）区切りで複数のメールアドレスを登録することも可能です。
アーカイブ使用容量 現在のアーカイブファイルの保管容量と、ファイル数を表示しています。
エクスポート使用容量 現在のエクスポートファイルの保管容量と、ファイル数を表示しています。
テンプレートに関する設定(→テンプレート編集)
テンプレート編集 ファイル配布、収集時に使用する、メール本文のサンプルテンプレートや、メールヘッダ・フッタの編集を行うことができます。
メールヘッダ・フッダ 配布・収集・パスワード取得など、利用者から第三者に提供されるメールに挿入される固定ヘッダ・フッタを、付加する・しない設定を行うことができます。
ファイル削除に関する設定
ファイル削除 指定の日付以前のシステム上にあるファイルを、一斉に削除します。
削除したファイルは元に戻りません。慎重に作業してください。
ファイル定期削除 ファイルのアップロード日から、指定の日数を過ぎたファイルを、自動的に削除します。
削除したファイルは元に戻りません。慎重に設定してください。
使用容量通知に関する設定
警告メールを送信する容量設定 警告メールを送信するための設定です。設定する容量の割合を超えると警告メールが送信されます。
0を設定するとメールは送られません。
メールアドレス 容量超過の警告メールを通知するメールアドレスを設定します。","（カンマ）区切りで複数のメールアドレスを登録することも可能です。
使用状況通知設定 通知を有効にすると、個人フォルダ・共有グループのフォルダ（オプション）について、週次での使用状況推移がメールで通知されます。
SAML認証に関する設定(※SAML認証有効時のみ)
各項目名は、SAML認証サービスによって異なる場合があります。SAML認証サービス上での設定に使うURLもこちらで確認できます。
Issuer URL SAML認証サービスのメタデータ取得用URLを設定します。
SAML 2.0 Endpoint (HTTP) SAML認証サービスのログイン用エンドポイントURLを設定します。
X.509 Certificate SAML認証サービスのX.509証明書を設定します。
