各種設定

アクセス制限

アクセス制限は、管理者画面、ユーザ画面、引取・ダウンロード画面へのアクセスをIPアドレスで制限を掛けることができる機能です。
各画面毎にIPアドレスでのアクセス制限機能を利用するかどうかの設定と、利用する場合にアクセス可能なIPアドレスを登録する事ができます。
「登録IPアドレスのみアクセス可能」に設定した場合に、登録されたIPアドレスのみアクセスを許可します。
不正なアクセスがあった場合は、ユーザ画面に以下の画面が表示されます。

アクセス制限の有効・無効

各画面に対して、「全てのIPよりアクセス可能」または「登録したIPアドレスのみアクセス可能」かどうかの設定が行えます。

[注意]
管理者画面の「登録したIPアドレスのみアクセス可能」に設定した場合は、現在アクセスされている管理者様のIPアドレスを登録を行ってない場合、アクセスできなくなります。

IPアドレス編集

各画面毎の[編集]ボタンをクリックすると、IPアドレス編集画面へ遷移します。

IPアドレス編集画面では、「登録IPアドレスのみアクセス可能」へ設定した場合、アクセス可能なIPアドレスの追加、及び削除を行うことができます。
IPアドレス欄に登録するIPアドレスを入力し、[追加]ボタンをクリックしてください。IPアドレス一覧に、IPアドレスが追加されます。サブネットマスクも追加することが可能です。

登録したIPアドレスを削除する場合、一覧内の削除するIPアドレスを選択し、[削除]ボタンをクリックしてください。IPアドレスが削除されます。
IPアドレスの編集は行えませんので、該当のIPアドレスを一度、削除し追加を行ってください。

CSVファイルでの追加

CSVファイルを用いて、IPアドレスを一括追加します。
セキュリティ設定(アクセス制限に関する設定)画面にある、[CSVファイルで追加]ボタンをクリックしてください。

CSVファイルでの追加画面に遷移します。
[選択…]ボタンをクリックして、CSVファイルを選択してください。選択したCSVファイルが正しければ、[インポート実行]ボタンをクリックしてください。
CSVファイルでIPアドレス情報の追加が完了します。

CSVファイルの作成

CSVファイルは、一行目から対象,IPアドレスのように、各項目を半角カンマ区切りでご記入ください。1行につき1つのIPアドレスです。2つ目からは、改行してください。

また、Microsoft Excelを用いて、CSVファイルを作成することもできます。

Microsoft Excelでは、一行目からセルごとに対象,IPアドレスをご記入ください。1行につき1つのIPアドレスです。2つ目からは、下の行のセルへ移動してください。

Microsoft Excelでは、保存時フォーマット(windowsの場合は、ファイルの種類)を「CSV(カンマ区切り)（.csv）」を選択し、保存してください。

CSVエクスポート

登録されている全てのIPアドレス情報をCSVファイルの形式でダウンロードします。
セキュリティ設定(アクセス制限に関する設定)画面にある、[エクスポート]ボタンをクリックしてください。

[エクスポート]ボタンをクリックすると、登録されている全てのユーザ情報をCSVファイルでエクスポートします。ファイルをダウンロードしますので、お使いのパソコンに保存してください。

[注意]
エクスポートされたCSVファイルは、毎回同じファイル名がつきます。ダウンロードする時は、前回のCSVファイルとの混合にご注意ください。
