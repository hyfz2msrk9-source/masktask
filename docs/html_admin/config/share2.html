各種設定

グループ共有機能 > グループ共有に関する設定(※オプション)

グループ追加

グループを作成します。
[グループ追加]ボタンをクリックしてください。

グループ追加の画面に遷移します。
「部署の登録」「メンバーの登録」のタイトル部分をクリックすると、表示が拡大され、各項目を入力することができます。各項目を入力し、[追加する]ボタンをクリックしてください。

グループ名グループの名前です。
共有フォルダ名グループに対応する共有フォルダの名前です。
容量共有フォルダに割当てる容量です。下に使用できる最大容量を表示しています。ご参考ください。 グループの容量制限で、割当てなしを選択されている場合は、この項目は表示されず、設定することができません。(→グループの容量制限)
定期削除の日数指定された日数より前にアップロードされたファイルを削除します。0日を指定すると、定期削除は行われません。
グループ管理者
の登録		 グループには必ず管理者を設定します(1人のみ)。
ユーザを検索し追加してください。アカウント、氏名、メールアドレス、メモのいずれかを入力し[検索]ボタンをクリックすると、該当するユーザを表示します。 任意のユーザの同じ行にある[追加]ボタンをクリックすると、グループ管理者に設定が完了します。
グループ管理者には、全ての権限とグループメンバーの管理権限が付与されます。
部署の登録 グループに所属する部署が設定できます。
部署名入力し、[検索]ボタンをクリックすると、該当する部署を表示します。任意の部署の[追加]ボタンをクリックするか、[表示部署を全て追加]ボタンをクリックし、所属する部署を登録します。
メンバー検索、
ユーザ一覧		 メンバーを追加する場合は、メンバーを検索し追加してください。アカウント、氏名、メールアドレス、メモのいずれかを入力し[検索]ボタンをクリックすると、該当するユーザを表示します。
各ユーザの左側にある[追加]ボタンをクリックしてください。また、表示しているユーザ全てを追加する場合は、ユーザ一覧の右にある、[表示ユーザをすべて追加]ボタンをクリックしてください。
所属メンバー 現在、グループに所属設定しているメンバーを表示します。削除する場合は、メンバー名の右の[×削除]をクリックしてください。
メンバーを部署で追加した場合は、部署ごとに所属しているメンバーを表示します。
また、ユーザごとに権限を設定できます。 (→所属ユーザの権限)

グループに所属したユーザは、ファイル一覧に共有フォルダが表示されます。
ファイル一覧のフォルダ一覧に、共有フォルダと個人フォルダを表示します。

グループ編集

グループを編集します。

[注意]
ファイル配布をした所属ユーザがグループから外された場合、ファイル配布を通知している人がファイルをダウンロードできなくなります。

グループ一覧の各グループの[編集]ボタンをクリックしてください。

各項目を、入力、設定し直し、[変更する]ボタンをクリックしてください。グループの編集を完了します。

グループ削除

グループを削除します。

[注意]
グループを削除すると、共有フォルダに入っているファイルを、全て削除します。ファイル配布を通知している人がファイルをダウンロードできなくなります。慎重に作業してください。グループを削除しても、所属しているユーザは削除されません。

グループ一覧の各グループの[削除]ボタンをクリックすると、グループ削除の確認画面に遷移します。
内容を確認し、[削除する]ボタンをクリックしてください。グループの削除が完了します。

メンバー追加(CSV)

グループのメンバーをCSV形式ファイルで追加します。
グループ一覧の各グループの[メンバー追加(CSV)]ボタンをクリックしてください。

部署とユーザのインポートが可能です。
「部署のインポート」もしくは「ユーザのインポート」のラジオボタンをクリックしてください。[選択]ボタンから作成したCSVファイルを選択し、[インポート実行]ボタンをクリックするとインポートが開始されます。

部署を登録する場合、CSVファイルは、1行目から「部署名」、「権限」順でカンマ区切りで作成してください。権限は、「0(権限なし)」、「1(読込のみ)」、「9(読込と書込権限あり)」 で必ず入力してください。

ユーザAが部署Bに所属している場合は、ユーザAと部署Bの両方を登録することはできません。両方を登録しようとした場合は、部署の登録時はユーザは自動的に除名され、ユーザの登録時はエラーとなります。

部署を登録する場合、CSVファイルは、1行目から「部署」、「権限」の順でカンマ区切りで作成してください。権限は、「0(権限なし)」、「1(読込のみ)」、「9(読込と書込権限あり)」で必ず入力してください。

[選択]ボタンから作成したCSVファイルを選択し、[インポート実行]ボタンをクリックするとインポートが開始され、部署もしくはユーザが登録されます。

CSVエクスポート

グループのメンバー一覧をCSVファイル形式でエクスポートします。
CSVファイルでインポートを行う場合に利用することができます。グループ一覧の各グループの[CSVエクスポート]ボタンをクリックしてください。

部署とユーザのエクスポートが可能です。 「部署のエクスポート」もしくは「ユーザのエクスポート」のラジオボタンをクリックしてください。 [エクスポート実行]ボタンをクリックしてください。

CSVデータをダウンロードします。
