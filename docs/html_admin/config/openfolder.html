各種設定

フォルダ公開

フォルダ公開機能は、ユーザが作成した、個人フォルダのファイルをフォルダごと一括して送信する機能です。
作成したフォルダの中身をまとめて、渡したい人だけに送信する事ができます。

フォルダ公開機能を利用するには、以下の設定が有効になっている必要があります。

各種設定 → フォルダ公開に関する設定 → フォルダ公開機能 が「有効」
(→フォルダ公開に関する設定)

ユーザ管理 → ユーザの登録またはユーザ情報の編集 → フォルダ公開機能 が「使用する」
(→ユーザ追加)

上記いずれかが無効となっている場合、フォルダ公開機能は利用できません。

有効に設定した場合、ユーザの個人フォルダに[フォルダ公開]ボタンと [フォルダ公開情報]ボタンが表示され、フォルダ公開機能が利用できます。
なお、共有フォルダはフォルダ公開機能が適用されませんので、ご注意ください。

フォルダ公開機能が有効で、サムネイル表示機能がONの時、公開する個人フォルダの中にサムネイルの付いたファイルが存在すれば、サムネイル付きで渡したい人に送信することができます。
(→サムネイル表示機能)

受け取った側は、配布フォルダの中身を、サムネイル付きで表示することができます。フォルダの中身をイメージしやすいようなサムネイル画像をお付けください。　
なお、フォルダ内のファイルにサムネイルとして使用した画像ファイルは、フォルダ公開機能では配布することが出来ませんのでご注意ください。
フォルダ公開機能ではセキュリティ設定を毎回設定することができます。公開したい状況に応じて、様々なセキュリティ設定を行うことができ、高いセキュリティを確保しております。

なお、各種設定で、フォルダ公開のセキュリティである、パスワードロック機能の初期設定を行うことができます。

サムネイル表示機能

サムネイル表示機能は、使用中のフォルダ内に画像ファイルが存在する場合、画像をそのフォルダ内のファイルにサムネイルとして登録でき、管理しやすくする事ができます。
フォルダ公開機能が有効でサムネイル表示機能がONの時、公開するフォルダ内にサムネイルの付いたファイルが存在すれば、サムネイル付きで渡したい人に配布することができます。
共有フォルダはフォルダ公開機能が適用されませんので、サムネイル付きで配布することはできません。ご注意ください。
受け取った側は、配布フォルダの中身を、サムネイル付きで表示することができます。フォルダの中身をイメージしやすいようなサムネイル画像をお付けください。

[注意]
フォルダ内のファイルにサムネイルとして使用した画像ファイルは、フォルダ公開機能では配布することが出来ません。
ファイル単位でサムネイル付きのファイルを配布した場合は、受け取った側はサムネイル付きで表示することができません。

サムネイル機能を有効にする場合は、各種設定のフォルダ公開に関する設定でサムネイル表示機能を表示にするに設定して下さい。
(→フォルダ公開に関する設定)

フォルダ公開機能が有効時、サムネイルを表示するに設定した場合、ユーザの個人フォルダにサムネイル表示：ＯＮと表示され、サムネイル機能が利用できます。

フォルダ公開機能が有効時、サムネイルを表示しないに設定した場合は、ユーザの個人フォルダにサムネイル表示：ＯＦＦと表示されます。
