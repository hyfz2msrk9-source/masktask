ログイン

ログインエラー対応

ユーザ側のシステム画面で、ログインに失敗したときにエラーメッセージが表示されます。
そのエラーの内容と対応方法です。

通常表示されるエラー
アカウントまたはパスワードが正しくありません。
入力したアカウント、またはパスワードが間違っている場合表示されます。
このアカウントは有効期限が切れています。
各アカウントに有効期限が設定されている場合、有効期限の終了したアカウントはログインできません。
再度ログインする必要がある場合は、有効期限の設定を変更してください。(→ユーザ編集)
このアカウントはまだ有効ではありません。
各アカウントに有効期限が設定されている場合、有効期限前のアカウントはログインできません。
今すぐログインする必要がある場合は、有効期限の設定を変更してください。(→ユーザ編集)

AD(ActiveDirectory)サーバと連携している場合に表示されるエラー

AD(ActiveDirectory)サーバとは、ユーザ管理を行うサーバです。
システムはADサーバと提携してユーザを認証します。

ADサーバに接続できませんでした。
管理者にお問い合わせください。
サーバからAD(ActiveDirectory)サーバへの接続ができません。 ネットワークやADサーバの状態を確認してください。
アカウントまたはパスワードが正しくありません。
AD(ActiveDirectory)認証においてID/PWが間違っています。
もしくは、AD_ADMIN_USER、AD_ADMIN_PASSの設定が間違っているため、認証に失敗しています。
AD_ADMIN_USER、AD_ADMIN_PASSの設定を確認・変更するにはシステムのサーバ管理者にお問い合わせください。
ADアカウントにロックがかかっています。
管理者にお問い合わせください。
AD(ActiveDirectory)サーバのアカウントにロックがかかっています。ADサーバの管理者にお問い合わせください。
アカウントにシステムへのログイン権限がありません。
管理者にお問い合わせください。
このアカウントは、AD(ActiveDirectory)サーバでシステムへのログインが許可されていません。ADサーバの管理者にお問い合わせください。
システムアカウントの初期化に失敗しました。
登録可能ユーザ数を超えています。
管理者にお問い合わせください。
アカウント数が契約ユーザ数を超えるため、ログインできません。
ユーザ管理画面(→ユーザ管理)より、不要なアカウントを削除してください。
システムアカウントの初期化に失敗しました。
システムの容量が不足しています。
管理者にお問い合わせください。
容量が足りないためログインができません。
ユーザ管理画面(→ユーザ管理)より、不要アカウントの削除／既存アカウントの容量を削減するなどで、容量を空けてください。
システムアカウントの初期化に失敗しました。
ADアカウントのユーザ情報が不足しています。
（表示名、メールアドレスが必要です）
管理者にお問い合わせください。
AD(ActiveDirectory)アカウントのユーザ情報が不足しているため、ログインできません。
ADサーバにて、表示名、メールアドレスを登録してください。
システムアカウントの初期化に失敗しました。
ADアカウントのメールアドレスが他のアカウントのメールアドレスと重複しています。
管理者にお問い合わせください。
AD(ActiveDirectory)アカウントのメールアドレスが、他のアカウントのメールアドレスと重複しているため、ログインすることができません。
他のアカウントのメールアドレスを変更してください。
